# 中国厅的形制与视觉系统（中式美学落地）

2026-09-29 · 配套机读版 `look.json`。
**怎么用这份文件**：这是形制和质感的方向与起点，不是规则表。色值、秒数、比例都是**起点**，要在样板厅上看了再调；用户否定过的底线（见 §6 末）才是硬的。
标记：**〔实〕**有出处或本机实测；**〔设〕**我推的起点；**〔核〕**上墙前要核；**【建议】**范围外的相关提议，决定权在用户。

## 0. 一句话总纲

西方厅是"画挂在墙上，人站在画前"；中国厅是"**画在人手里、案上、墙上、洞里，各有各的看法**"。
同一个引擎，但每厅先定"这件东西古人怎么看"，挂法、镜头、交互、换厅都从这里长出来。

依据（都是展厅里可以写上墙的）：
- 宋人把"挂画"与烧香、点茶、插花并称"四般闲事"（吴自牧《梦粱录》〔实，原文"不宜累家/戾家"两种写法，且原语境是四司六局代办的差事，引用时只取"挂画是日常雅事"一层〕）。画是**生活里的东西**，不是神龛里的东西。
- 文震亨《长物志·位置》："悬画宜高，斋中仅可置一轴于上，若悬两壁及左右对列，最俗。"〔实，维基文库四库本〕这句话本身就是本馆"每厅只挂一件"的中国版理由，**可做中国厅序厅的第一句墙文**。
- 赵希鹄《洞天清录·序》："明窗净几……时取古人妙迹以观……摩挲钟鼎，亲见商周。"〔实，ctext〕看画要"取"出来，看铜器要"摩挲"——这就是展卷和把玩。
- 宗炳"澄怀观道，卧以游之"（《宋书·宗炳传》）；郭熙"可行、可望、可游、可居"与三远（《林泉高致》）〔实，见 aesthetics_theory.md [S2]、visual_refs.md §2.1〕。

## 1. 观看方式 → 挂法（六种）

每种挂法都回答四件事：**放在哪（构图）**、**停留时镜头怎么"看"**、**观众能怎么动它**、**进厅/出厅时它自己怎么动**。
共同原则：
- **先全貌，再细读，最后回全貌**（visual_refs §2.5 的四拍，按网页停留改成循环）。全貌停足，转场遮画时间尽量短（用户偏好 2）。
- **镜头只做这件东西本来的动作**：手卷横移、立轴上行、册页翻开、器物转动、石窟仰视、书法循笔顺。**不做**西方式的推拉（Ken Burns 一律推近）、3D 飞入、景深虚化。
- 平移速度上限约每秒 1/7 窗口宽，细线密的画再慢〔实，visual_refs §0-4 引摄影界 7 秒规则〕；起止各 ≥1 s 缓入缓出，或用"一笔三段"曲线（藏锋起、行、回锋收）〔设〕。
- 动效要一眼看得出在动（用户认可北宋片"峰顶先露""柔光扫釉"的力度），但同一时刻只有一个主运动。

### 1.1 手卷 handscroll —— 案上横展，右→左，边展边收

**真实看法**〔实〕：手卷平放在案上，左手展开新的一段，右手把看过的卷回去，一次只露出约一臂（一肩）宽（Met《Chinese Handscrolls》、哈佛 Careful Handling、哥大 Song module，均见 visual_refs §2.2）。故宫 2017 年《千里江山》特展专门做了能把全卷 1191.5 cm 从头到尾展开的长柜——那是例外，平时就是一段一段看〔实，故宫博物院公告〕。

**与先例的区别**：故宫《清明上河图 3.0》（2018）把长卷做成巨幅动态互动影像，让人"进入"画里〔实〕；我们反过来——**原作像素不动，观众像古人那样展卷**。惊艳来自"卷"这个动作本身，不来自重画。

**构图（1389×713 起算）**
- 屏幕下部是一张**长案的案面**（素漆或素木，按朝代换），占屏高约 12–18%〔设〕；手卷躺在案上，案面在画下留出一条"桌沿"——这条桌沿就是观众"坐在案前"的位置感。
- **两个卷轴筒**：左边是还没展开的部分（绕在尾端"轴"上，看到的是卷背的背纸和两端轴头），右边是已看过的部分（绕在"天杆"上）。**两个筒的粗细随进度变化：左筒越看越细、右筒越看越粗**——这就是进度，不需要进度条。筒用 canvas 画圆柱明暗（线性渐变 + 背纸纹理横向滚动），每帧只重绘两端，成本很低。
- 中间展开段 = structure.md C1 的 `band` 窗口（带宽约 1087 px，带高约 300 px）。上下是装裱的**绫边/局条**（窄，1–2% 带高），不是画框。
- 展签不放右侧栏，改放案面上方左侧或下方，**竖排**（像压在案头的一张签条），距画 ≥32 px（DESIGN-RULES §1）。

**全卷缩略条：做成"卷的解剖"，不做成滚动条**
- 位置：案的**前沿**（桌沿线下方）一条细带，高 18–28 px〔设〕。
- 内容：按真实装裱顺序从右到左画出整卷：`天杆｜包首｜(隔水)｜引首｜隔水｜画心｜隔水｜拖尾(题跋)｜轴`。每段用它真实的材质色：包首锦/绫、引首常见洒金笺或题字纸、隔水绢/绫、画心是这卷画的缩略、拖尾是纸和题跋的墨块。各段比例按原件实测（查不到的段按图像里能看到的算，不编）。
- 当前展开的那一臂**亮**，两侧卷起的部分用背纸色压暗（与上面两个筒的粗细一致）。**不画矩形框**。
- 段名只在悬停/长按时用小号竖排字出现（"引首""画心""拖尾"），平时没有字。点一段 = 卷过去（卷动速度受上限约束，中途两个筒真的在转）。
- 印章、题跋在缩略条上是朱点和墨块——观众一眼看出"后面还有人写了很多字"。拖尾的题跋是**中国手卷特有的"画的历史写在它自己身上"**，全卷样板应该让自动卧游走到拖尾停一次。

**停留时的"看"：自动卧游 = 分段展、停、再展**
- 不是匀速平移。真实展卷是"展一段 → 看 → 收一段 → 再展"。所以自动卧游：每步推进约 0.5–0.7 个窗口宽，用 3–4 s，缓入缓出；停 5–8 s；有 `tour` 注记的段落停更久（structure C1 已定 `tour:[{x,t,note}]`，note ≤18 字，过核查）〔设〕。
- 每一步推进时两个筒同步转动，有极轻的纸/绢摩擦声（§4）。
- 观众一碰（拖、滚轮、触摸板横滑）就停止自动；拖动带惯性和阻尼；←/→ 仍归引擎换厅（structure C1）。

**进/出厅**：进厅 = 解带、展包首、露出引首（有引首题字的卷，引首本身就是一个"那一刻"）；出厅 = 快速收卷至包首（≤1.2 s）。详见 §2.3 换厅。

**素材**：两个筒的背纸纹理用已有 `trailer/assets/textures/paper_*`；包首锦、绫用 `ling_mount_2048`（黄色引首绫的比值纹理，可重新着色）〔实，textures/silk_README.md〕；画心切片按 structure C1。

### 1.2 立轴 hanging scroll —— 挂起来，从下往上

**真实看法**〔实〕：立轴挂在斋壁上，"悬画宜高"（《长物志》）；看山水立轴，郭熙"自山下而仰山巅谓之高远"。宋人巨嶂式山水正是"一座山正面立起来"（李泽厚 9.2）。

**构图**
- **整幅装裱挂在素壁上**：挂绳 → 天杆 → **惊燕**（两条窄绫垂在天头上）→ 天头 → 上隔水 → 画心（四周窄局条）→ 下隔水 → 地头 → 地杆与两端**轴头**（突出画边）。
  - 原件照片若有装裱，用原件装裱图；只有画心的，墙上挂"画心 + 简化装裱"，在作品栏注明"装裱为示意"（structure C2 做法 2），**不伪造某件原作的装裱**。
  - 天头:地头比例用通行的"天头长、地头短"，具体数不写上墙〔核〕。
- 立轴不贴墙死平：地杆有厚度，下半截离墙一点，墙上有很淡的**非对称软影**（上窄下宽），不是西方画框那种四周均匀的投影。
- 两侧的空墙不是虚空：一侧放竖排展签（像题跋占住空白，visual_refs §2.3），另一侧留白。

**停留时的"看"**
1. 全貌 6–8 s（窄也要先看全）；
2. **从山脚开始，向上走**：纵向窗口放大到画心宽铺满，从最下端（溪涧、行旅）慢慢上行，经云烟，**主峰最后出现**（用户认可"峰顶先露"的力度，这里是它的静态版本）；
3. 回全貌。
- 用 structure C2 的纵向窗口（`kind:"hangingscroll"`）；右侧窄的纵向缩略条同样做成"天头—画心—地头"的解剖图，不做滚动条。

**进/出厅动作**：惊燕在换厅那一口气里轻轻飘一下（像门开时的风）——这是全馆最小的"动"，却一眼看得出是中国立轴。进厅可以用"**挑轴展挂**"：画从天杆处自上而下垂落展开（真实挂法：先把天杆挂上，再让画轴自己往下放开）。

### 1.3 册页 album —— 一开一开翻

**真实看法**〔实，装裱常识，具体术语上墙前核〕：册页放在案上翻看；左右翻的叫蝴蝶装，上下翻的叫推篷装，展开成长条的叫经折装。常见一面是画、对面是"**对题**"（题诗或题跋）。

**构图**：案上一本展开的册，两页对开。**对题页就是这一厅的展签位置**——右页画，左页用霞鹜文楷竖排写作品信息和那一句（中国书画的正统版式，同时解决"文字不压画"）。对题页上的真实题字，如果原册有，就显示原迹 + 小字释文。
**停留时的"看"**：一开停 8–12 s，然后翻到下一开。翻页做成**纸页绕书脊的平面翻转**（一次性的 2D 变换 + 页背纸纹 + 书脊处阴影），**不做 3D 卷角**（西方电子书的 page-curl）。
**观众能做**：拖页角翻页，翻得慢页子跟手，松手按速度决定翻过去还是落回。
**适合**：南宋小品、八大山人《安晚帖》这一类〔核选件〕。

### 1.4 器物 object —— 放在座上，拿在手里转

**真实看法**〔实〕：书斋里的器物放在配好的木座上，看的时候取在手里转着看，翻过来看底——《洞天清录》说"摩挲钟鼎"。清宫的器物有配座、囊匣。汝窑水仙盆底部刻有乾隆御题诗（本机素材已有底部照片，见下）。

**构图**：器物坐在它的**木座**上，座在案上或平台上；背后是墙，**一侧有窗**——窗纸透进来的散光从侧面落在器物上（不是顶上打下来的舞台聚光）。
**停留时的"看"**：
- 瓷器：**光在动，器不动**——窗光在停留期间缓慢移过釉面（用户认可"柔光扫过釉面变色"）。实现：器物抠图（mask）内叠一层预渲染的柔光渐变，`soft-light`/`screen` 混合，只在器物内；关键效果预渲染，别依赖 Safari 不支持的 `ctx.filter`（LESSONS §4）。
- 青铜：光掠过纹饰，凹凸显出来；**不做金属高光、不做金色**（aesthetics_theory §2.3）。
**观众能做（把玩）**：
- 横拖 = 转器物。真实可行的只有两条路：①用原件已有的多角度照片做分段切换（汝窑有正面、侧面、底边、底面四类 CC BY 4.0 照片〔实，series/assets/INDEX.md §2〕）；②找得到公开 3D 模型才做连续转〔核，未找〕。**没有素材就不假装能转**。
- 上拖/双击 = **"翻过来看底"**：器物翻起，露出底部——汝窑那张 `ru_spurs_PBG.jpg` 有六个支钉痕和乾隆御题诗〔实〕。这是全馆最"把玩"的一刻。
**青铜的中国式看法**：旁边并挂**铭文拓片**或**全形拓**（清代金石学把整件青铜器用传拓表现在纸上，再题跋成轴，是文人"看"青铜的方式〔核：具体的全形拓作品与作者，如六舟，上墙前核〕）。器物本身 + 纸上的拓 = "金石气"的来源。

### 1.5 石窟 / 造像 grotto —— 走进去，仰着看

**真实看法**：石窟是进去看的；大像要仰视。云冈部分洞窟在窟门上方开**明窗**，外光从明窗照到佛像上部〔核：明窗的采光作用在权威资料里的说法〕。敦煌研究院"数字敦煌"2016 年上线，提供 30 个洞窟的高清图与全景漫游〔实，新华网等〕——那是"走进去看"的标杆，但它是 360° 全景，我们不做 3D，做"入口 → 仰视"的 2D 版本。

**构图**：屏幕先是**洞口**（真实照片里的窟门/明窗轮廓，暗），进厅时从洞口"走进"——用两层平面（洞口一层、窟内一层）的轻微视差，不是 3D 飞入。
**停留时的"看"**：从**莲座与脚**开始向上，经衣纹，**脸最后出现**（北魏"秀骨清相"的微笑、唐的丰满，李泽厚 6.1–6.2）。光来自明窗/窟门方向，是散的、偏冷的天光。
**壁画洞（敦煌）**：壁画是整面墙，按经变画的布局横向走（散点，像手卷在墙上），颜料层的剥落、变色（例如铅丹变黑〔核〕）是时间的材料，可做转场。
**观众能做**：拖着"抬头/低头"；或手持一盏**油灯**在暗壁上照（古人在窟里就是燃灯看壁画〔核〕），灯照到的地方才显色——这是有物理手感的展项候选，不是说明性开关。

### 1.6 书法 calligraphy —— 循笔顺，看行气

**两种物质，两种看法**
- **碑 / 拓本**：石上刻字，纸上捶拓，**黑底白字**。拓本常剪裱成册（剪裱本）或整幅装成轴。
  - 构图：墙上一张墨拓，四周露出拓纸的白边和折痕；墙色取深（墨拓本身就很"重"）。
  - 进厅动作：**拓出来**——一张白纸覆在（看不见的）石上，拓包一下下扑墨，白字从黑里显出来。这是中国特有的"显影"，动效一眼可见，而且真实（用户认可"动静结合"）。
- **墨迹 / 帖**：纸或绢上的原迹。
  - 构图：先看**通篇**（章法、行气：一行一行的呼应与欹侧），全貌停足。
  - 停留时的"看"：**镜头循笔顺走**——从右边第一行顶上开始，顺行向下，行尾接下一行顶上，速度跟着这件字自己的节奏（行书连绵处快，停顿、涂改处停）。《祭侄文稿》的涂改就是停顿点（plan_draft "祭侄"）。
  - 进厅动作：**按笔顺落墨**（用户认可的片头力度）：用原迹做遮罩，沿真实笔顺预渲染显出，不是字体动画（aesthetics_theory §3"笔顺错误的写字动画"）。笔顺路径要人工核（行草的连笔尤其）。
- **观众能做**：拖动一个"笔尖"沿着原迹走，走得慢墨浓、走得快出飞白（THEMES 展项点子）；或在碑厅亲手"捶拓"。

### 1.7 屏风、书斋、雅集（空间母题，给展厅和转场用）
- **屏风**：五代《韩熙载夜宴图》用屏风把一卷分成几段场景；周文矩《重屏会棋图》画中有屏风、屏风里又画着屏风〔核〕。若挂这类作品，**屏风就是它自己的分段符号**，换厅可以"屏风移开"（§2.3）。
- **书斋**：明窗、净几、一轴、一器、一炉——宋至明的斋室是本馆墙面语汇的主来源（不是宫殿，不是庙）。
- **雅集**：兰亭（曲水流觞）、西园雅集——"一群人围着一张案看一卷画"。门厅（§5）可以用这个意象。

## 2. 空间与色

### 2.1 墙 / 底：随朝代的**材料**走，不是一律米黄

原则：墙取"这件东西当年所在的材料"或"装它、衬它的材料"——黄土、夯土、铸范、漆、岩壁、绢、宣纸、粉墙、绫、紫檀、白立方。
色值是起点〔设〕，上墙前用所挂原作的高清图实测周边色调（aesthetics_theory §2.3 的方法）。ink 为墙上文字的明暗，core 会按墙色算 `--ink-2/--ink-3`（DESIGN-RULES §4）。

| 段 | 墙/底的材料 | 墙色起点 | 强调色（只来自原作） | 光 | 节奏与质感（按《美的历程》） |
|---|---|---|---|---|---|
| 新石器·彩陶 | 黄土、半地穴房屋的夯土壁 | #6E5438 土黄褐（暗） | 陶红 #A0553A、黑彩 | 低处门道的日光，横着进来，暖 | 绕器身一圈的节奏：纹样在转，"有意味的形式" |

- 墙不是纯色平涂：每种墙有一张**真实材料**的低对比纹理（绢、纸、绫已有，〔实〕textures/；土壁、砖、岩壁、漆需找公有领域扫描或自拍），纹理对比度压到几乎看不出，只让墙"有质"。
- 这张表里明暗是故意拉开的：最暗是商（青铜），最亮是南宋一角、元纸本和当代。用户嫌过"太典雅淡雅"——所以**不是全馆一个水墨灰**。
- 中间调墙（竹灰青、砖灰）按 DESIGN-RULES §4 由 core 算文字色，不用透明度调暗。
- **"以壁为纸"**：贝聿铭在苏州博物馆把白粉墙当纸、切片石当画，复刻米氏云山〔实，苏州市园林局〕。明/江南厅的粉墙可以借这个思路：墙就是纸，窗格影、竹影落在上面就是一幅会走的画——但只在墙上，不上作品。

### 2.2 光：中国室内的光是**散的、侧来的、随时辰走的**

- **来源**：窗纸、直棂窗、花窗/漏窗、竹帘、窟门与明窗、油灯/烛（夜宴、石窟）。
- **做法**：墙上叠一层很淡的"光场"：从窗一侧来的柔渐变 + 窗格的模糊投影（一张预渲染的模糊窗棂 PNG，按朝代换窗型：宋直棂、明花窗、清冰裂纹〔设〕），在停留期间**极慢地移动**（像日影），整个停留移动约一个窗格宽。**只画在墙上，绝不画在作品上**（DESIGN-RULES §5）。
- **不用**：舞台聚光（一圈光晕打在画上）、画框顶灯、体积光、丁达尔光束、镜头光晕（aesthetics_theory §3）。西方厅的"熄灯换厅"本身也是剧场语言，中国厅用 §2.3 的材料动作代替。
- 例外：商青铜厅可以用"火光"（祭祀的火），但只是低处一片暖色的轻微起伏，不是闪烁的特效。

### 2.3 换厅的方式（西方是熄灯，中国给三个选项）

换厅是转场外面的"底层手势"：从离开这一厅到下一厅转场开始之间的那一口气，≤1.5 s，不与转场的"发现"抢戏，不遮下一件作品，不剧透下一件。

**选项 A「收卷—展卷」（推荐作为全馆默认）**
- 出：墙上/案上的作品被"卷起"：手卷两筒合拢、立轴自下而上卷回天杆、册页合上、器物收进囊匣（盖子合上）。卷起后画面只剩墙。
- 入：下一厅的墙色从卷起处像纸一样展开铺满，然后转场开始。
- 为什么：这是中国书画本来的"收"——看完就卷，下次再展；每种挂法各自有"收"，所以全馆统一又不单调。
- 实现：canvas 把快照（structure C1 已定：离开那一刻对挂着的画拍快照）按圆柱卷起；立轴卷起是纵向同一算法。约 1 天引擎工作。
- 风险：若签条上写下一厅的名字就是剧透——**签条留空或只写本厅名**。

**选项 B「隔扇开合 / 屏风移开」**
- 出：两扇隔扇（格心透光的木门）合上，格心的窗纸透着下一厅的墙色；入：隔扇向两侧**开启**（绕门轴转，不是推拉）。屏风版本：一扇屏风从画前平移开。
- 注意：**推拉门（移门、障子）是日本的**，中国隔扇是开合的，屏风是搬移的（§6 反面清单）。
- 适合：园林/书斋气的厅（明、宋），以及挂《夜宴图》《重屏会棋图》这类画中有屏风的厅。

**选项 C「日移—掌灯」**
- 出：窗格光斑在墙上走过、变暗（日落）；入：下一厅的光从它自己的光源亮起（窗、明窗、灯）。
- 适合做全馆默认的"最轻"版本；与西方"熄灯"最接近，但是时辰，不是舞台。

**不推荐作为每厅手势**：落一方印（印是有意义的所有权记录，每厅一方就成了装饰，aesthetics_theory §2.4）。**印只在两个地方用**：中国厅序厅（本馆自刻的一方馆印）和尾声（最后一方），或者转场本身讲的就是某件作品上的真实收藏印。

## 3. 文字

### 3.1 竖排
- 竖排（`writing-mode: vertical-rl`，列从右往左）：厅名、一句话、展签、题跋式引文。
- 横排：阅读面板的长文（structure C3 的结论：面板竖排与滚动、渐隐、lint 全冲突，收益小）。
- **竖排列序必须从右往左**（`vertical-rl`，不是 `vertical-lr`）——后者是常见错误。
- 页面 `lang="zh-Hans"`：CJK 字形按 lang 选，漏了会在部分系统上回落成日文字形（§6）。

### 3.2 字体（OFL，自托管）
| 用途 | 字体 | 理由 |
|---|---|---|
| 正文、展签 | 思源宋体（Noto Serif SC） | 宋体是印刷的正体，与西方厅同源（`--song`），馆内统一 |
| 引文、题跋、对题页 | 霞鹜文楷（简体版 npm `lxgw-wenkai-webfont`） | 楷书是手写的正体，与引文"有人写下"相配；需 engine 支持 `fonts.local`（structure C6） |
| 作品栏小字（可选） | 朱雀仿宋〔核许可〕 | 仿宋是古籍注文、公文的传统用字，小字易读 |
| 厅名题签 | **原迹集字**（见 3.4） | 不用 Ma Shan Zheng 等仿书法字体做标题（aesthetics_theory §2.4、structure C6） |

### 3.3 竖排里的标点与数字（据 GB/T 15834—2011 §5.2〔实〕）
- 句号、逗号、顿号等"置于相应文字之下偏右"（§5.2.1）——由字体的 `vert` 特性给出，Noto Serif SC 按大陆规范；上线前实测（structure C3 已列 30 分钟实测项）。
- **引号改用直角引号**：双引号 ﹃﹄，单引号 ﹁﹂（§5.2.3）；括号用 ︵︶。这是竖排对 DESIGN-RULES"不用「」"的例外，要写进 DESIGN-RULES 的竖排一节。
- **书名号**：国标竖排用**浪线式书名号"﹏"标在字的左侧**（§5.2.4），这也是中华书局竖排点校本的传统。CSS 可做：`text-decoration: underline wavy; text-underline-position: left`〔核 Safari 效果〕。另一个选择是常见的旋转书名号 ︽︾。→ **待用户拍板**。
- 年份用汉字：竖排写"一一一三年"或"北宋政和三年（一一一三）"〔核年号〕；公元前写"公元前一六八年"。
- 一两位数字（如"第 20 窟"）用 `text-combine-upright: all` 横在一格里；三位以上一律汉字。**不用** `digits` 值（支持差，structure C3）。
- 尺寸：竖排展签只写"纵二四·八 横五二八·七厘米"一类汉字写法，或把尺寸留在横排作品栏（DESIGN-RULES §3 的 meta 三行）→ 实现时二选一，推荐后者（少一个竖排数字难题）。
- 避头尾（§5.2.6）：`line-break: strict` 在竖排同样生效。

### 3.4 厅名 = 题签，用本朝原迹集字：**厅名本身就是一部书体演变**
- 每厅厅名（≤5 字，现方案多为 2 字）从**该朝代的原迹**里集字：商周取金文拓本，秦取小篆（刻石拓本），汉取隶书碑，魏晋取王羲之系行书，唐取颜真卿，宋取苏黄米蔡，元取赵孟頫，明取文徵明/董其昌，清取邓石如/吴昌硕一路的金石书，近现代取齐白石。**史前（彩陶）没有文字，用思源宋体**，这本身就是一句诚实的话。
- 走完全馆，观众会在厅名上看到字体从铸、刻、写到写意的变化——这是"书画同源"与"线的艺术"（李泽厚 2.2）的一条不说破的暗线。
- 每个字记出处（帖名、行、字序），厅里查不到那个字就换同时代另一件，仍查不到就用宋体，**不拼、不造**（aesthetics_theory §2.4）。
- 碑拓集字是黑底白字，按墙色反相或做成白文效果；墨迹集字要抠干净，保留飞白。
- 题签放在一条**签条**上（窄绫/纸条，竖排），位置按朝代：宋以前"藏"在画外，宋一线细楷贴边，元以后可进构图的空白处（李泽厚 9.4 的题款位置演变，aesthetics_theory §2.4）。

### 3.5 展签像签条、题跋
- **签条式展签**：窄长竖条，上写《题》（大）、下写作者与朝代（小），像手卷包首上的签。
- **题跋式引文**：引画论原文（谢赫、郭熙、张彦远、苏轼、倪瓒、石涛），霞鹜文楷竖排，出处像落款一样在末行下方、字号小一档。**不加假印**；需要朱色的，只在真实印章图像处。
- 引文与出处上墙前逐条核（任务要求；aesthetics_theory 已核过一批，其余标〔核〕）。

## 5. 门厅：东西并置，一眼看出东西之别

在 structure.md B1 已推荐的"两列等距 + 同时期连线 + 年份尺（镇纸）"上，加形制：

- **一堵墙，一张案**：
  - **西方一侧是展墙**：竖向一列小画框（各厅墙色的色块 + 作品缩略，悬停放大），横排文字，衬线字体，保持西方厅现有语言。
  - **中国一侧是长案**：一张长案上**按年代由上到下叠放各厅的"藏品"**，每件按它的形制用它的"装"——手卷是一卷系着带子的卷（包首上有竖排签条）、立轴是一卷带轴头的轴、册页是一册、器物是一只囊匣（锦盒，盖上有签）、石窟是一册拓本或一张壁画照片的卷。签条上是该厅的集字厅名。
  - 于是不看字也知道：左边是"挂在墙上看"，右边是"从案上取来看"。
- **同时期对照**：两列之间一条**墨线**连同时期的厅（B1 已定）；墨线用笔画式的细线，起笔略重、收笔回锋，不用西式的等宽直线。
- **年份尺 = 镇纸**：B1 的"镇纸沿年代拖动"——做成真实的一方石镇纸或铜镇纸（形状取自某件真实文物〔核〕），拖到哪年，右边那卷的签条亮起（像被抽出一点），左边那幅框亮起。
- **进门**：点中国侧某件 = 那一卷被"取出"（抽出一段、解带），然后进入 `/china/#<id>`；点西方侧 = 那幅画亮起放大，进 `/west/#<id>`。两个进门动作本身就展示了两种观看方式。
- **窄屏（390 px）**：两列竖排，中间墨线；B1 定"中国在左、西方在右"，而中式阅读从右起——**哪边在左是待拍板项**（structure 待拍板 #3，USER_DECISIONS 未定）。
- 门厅不出声（B1）。
- 门厅墙色：中性的暗暖灰（介于西方厅入口 #161210 与中国厅宋绢之间），让两边的材料对比来说话。

## 6. 反面清单：廉价"中国风" / "西方展厅换皮"，以及替代

（第 1–13 条沿用 aesthetics_theory §3 的核心，这里只列与"形制与视觉"直接相关的，并补上"换皮"一类。）

| # | 做法 | 为什么不行 | 替代 |
|---|---|---|---|
| 1 | **西式画框挂中国画**：金框、白卡纸、四周均匀投影 | 中国书画的"框"是装裱，是软的、可卷的 | 手卷上案、立轴有天头地头惊燕、册页对开；影子不对称 |
| 2 | **所有作品一律 Ken Burns 推近** | 西方单点透视与摄影逻辑 | 每种挂法只做它本来的动作（横展、上行、翻开、转动、仰视、循笔顺） |
| 3 | **聚光灯/画框顶灯/光晕** | 西方剧场与美术馆语言 | 窗纸散光、窗格影、明窗、油灯 |
| 4 | **全馆一个"水墨淡雅"模板**（米黄底 + 灰墨） | 用户嫌过"太典雅淡雅"；各朝审美不同 | §2.1 按材料换墙，商最暗、南宋最空、清最繁 |
| 5 | 红金配色、满屏祥云回纹如意、中国结灯笼熊猫太极 | 节庆与旅游纪念品的符号 | 墨 + 底材 + 原作自己的颜色；朱只给真印 |
| 6 | 书法字体做标题/字幕；笔顺错的"写字"动画 | 字体不是书法；懂的人一眼看穿 | 原迹集字（注出处）；落墨按原迹笔顺预渲染 |
| 7 | 印章当角标装饰；假古印 | 印是所有权和经手的历史 | 只用真印；馆印只在序厅和尾声 |
| 8 | **竖排但列从左往右**（`vertical-lr`）；竖排里横躺的标点和阿拉伯数字 | 排版不专业 | `vertical-rl`；直角引号；汉字年份；GB/T 15834 §5.2 |
| 9 | **日本元素混入**：推拉的障子/移门、枯山水、和纸花纹、樱花；漏写 `lang` 导致日文字形 | 外国观众最容易把"东亚风"当"中国风" | 隔扇开合、屏风移开；`lang="zh-Hans"`；纹理只用中国原作取的绢纸 |
| 10 | 3D 卷轴模型：卷轴翻飞、3D page-curl 翻页、镜头飞进山水 | 西方 3D 逻辑；游戏 UI 感 | 平面卷筒（只是圆柱明暗）、纸页绕书脊的 2D 翻转、两层平面视差 |
| 11 | 剪贴画式卷轴（红天杆 + 金轴头 + 羊皮纸色） | 这是贺卡模板 | 轴头用真实材质（木、玉、瓷、牙等，按原件照片），绫用实测色 |
| 12 | 仿古做旧：泛黄滤镜、暗角、划痕、胶片颗粒 | 旧是假的 | 原作自己的旧色（宋绢实测 #585330 一类） |
| 13 | 过饱和石青石绿、湖蓝翠绿 | "电脑色" | 实测的灰蓝灰绿 |
| 14 | 墨滴落水、墨团溶解、墨迹擦除等水墨转场模板 | 就是"斑块溶解"（用户否定） | 墨从上一件作品里真实的那一块洇开（THEMES 点子 1） |
| 15 | 雾/烟霭到处用 | 用户：雾全馆最多一次，且不遮画 | 雾只留给最该用的那一厅（宋山水"烟霞锁其腰"是首选候选）；其他厅用雪、水、月、窑火、墨晕、泥金等 |
| 16 | 进度条、滚动条、白色 UI 缩略条 | 像软件 | 卷筒粗细 = 进度；缩略条 = 卷的解剖（引首—画心—拖尾） |
| 17 | 合成古筝刮奏、史诗弦乐、锣钹冲击 | 声音上的红金配色 | 真实录音，稀疏；物的声音；那一刻前的安静 |
| 18 | 史诗旁白式墙文："五千年""泱泱华夏" | 口号不是美学 | 一件东西、一句发现，引原典并注出处 |

**用户否定过的底线（硬）**：拼贴感（切块、抠人贴来贴去）、橡皮变形、斑块溶解/矩形分块显现、漂浮剪影、放大到糊、提前剧透下一件、转场串朝代却没有信息、移动太快晃眼、全景尺度把画切成条、转场遮画太久、雾多。本文件里的每个挂法和换厅都按这些检查过：例如手卷不在墙上切成条（用案上一臂窗口 + 卷筒），签条不写下一厅名。

## 8. 待用户拍板
1. **换厅默认手势**：A 收卷—展卷（推荐）/ B 隔扇·屏风 / C 日移—掌灯；或 A 为默认、B/C 按厅用。
2. **竖排书名号**：国标浪线式"﹏"（古籍点校本传统，更"中国"，需实测）/ 常见的 ︽︾。
3. **厅名集字**：做"厅名本身就是书体演变"的集字题签（要逐字查出处，每厅约 1–2 h）/ 统一用思源宋体。
4. **门厅左右**：中国在右（中式从右读起）/ 中国在左（structure B1 原稿）。
5. **墙色的明暗跨度**：按 §2.1 从最暗（商）到最亮（当代白立方）拉开 / 收窄到中间调。当代徐冰厅用白立方是否接受。
6. **石窟厅的"油灯照壁"**：作为展项（有手感）/ 只作停留时的光。
