# 中国厅转场与展项发散 · 材料与工艺视角

2026-09-29 · 机读版 `design_craft.json`。展厅清单按 `halls.json`（19 厅 + 尾声），形制按 `look.md`。

这份方案专攻“中国艺术的物质”：观众在转场里看一种材料或工艺怎样变成下一件作品。泥范敲开是一只鼎，钴料入窑前是黑的，一滴墨干成一只眼睛。每处 1–2 个方案，A/B 旁标了本视角的推荐。每个方案都写了观众亲身感到的是哪个美学观念或哪一朝的审美。

## 一、先看这几条

**最得意的 3 处**

1. **彩陶 → 吉金「泥范敲开，吉金是金色的」**：同一种泥做成范，铜水注入，泥范按真实分块敲落，露出的是一只**金黄**的鼎，随后“老”成今天的青黑。观众心里的青铜都是绿的，这一下把“吉金”二字讲明白了；动作是真实的铸造工序，不是特效。
2. **富春 → 青花「入窑前是黑的」**：元人画水墨的笔在白坯上画龙，钴料上坯是灰黑的，像墨；一窑火过去，黑变成了蓝。观众以为在看又一幅水墨，火一过成了青花，书画同源一路延伸到了瓷上。实现只是同一张瓶图的调色，不变形。
3. **九色鹿 → 卢舍那「石头决定了佛」**：两记凿声，砾岩上一凿打滑，石灰岩上一凿咬进去刻出衣纹，镜头顺衣纹抬到佛脸。观众用耳朵就懂了为什么敦煌是画、龙门是刻，也从暗窟走进了唐的露天晨光。

另外两处联系最巧的：**蛙声 → 天书「蝌蚪成了读不出的字」**（古人把读不出的古字叫“科斗书”）、**写意 → 八大「明珠落，白眼开」**（湿墨在空白里下坠，干成焦墨，落成白眼的眼珠）。

**全馆的材料线**（推荐方案）：窑火 → 陶范与铜 → 铭与陶戳 → 漆、白膏泥、木炭 → 丝与纸 → 墨线 → 泥壁与土红 → 砾岩与石灰岩 → 石点与墨点 → 立轴与手卷 → 水与釉 → 釉光与空白 → 干笔飞白 → 钴与窑火 → 生宣洇墨 → 湿墨与焦墨 → 白描与重彩 → 画出的水与留白 → 纸与雕版 → 卷。相邻两处没有重复的材料；火出现三次（入场冷却、吉金熔铜、青花烧成），两次在开头相邻，下面第三节有搭配建议。

**雾：0 次。** 本视角没有用雾，全馆唯一一次雾的名额留给别的方案。整屏材料现象用的是窑火、铜水、雨（只在溪山 B）、天青颜色场、墨洇。

## 二、转场（入场 → 19 厅 → 尾声）

### 门厅 → 彩陶（`foyer` → `caitao`）· 推荐 A

**A「从窑火里冷出来」**（材料：陶 · 窑火）一只刚出窑的盆还红得发亮，热一点点退下去，陶的赭红和黑彩的人面鱼纹才从火光里“冷”出来：中国艺术的第一种颜色是火给的。

- 依据：半坡彩陶先在坯上用含铁、锰的矿物颜料画纹，再入窑氧化焰烧成，陶胎烧红、彩烧黑（通行；烧成温度约 900–1000°C 待核）。灼热物体按温度发出橙→暗红的光，是物理事实。
- 编排：① 0–2 s：p=0 = 门厅点选彩陶后的收束帧（案上那只“囊匣”打开后的暗色）；屏幕中间低处亮起一圈火光，无形无纹。② 2–5 s：镜头像人俯身一样向下看，火光里是一只圆口浅盆的轮廓，整只橙红发亮，看不到纹样；热浪只让盆外的背景微颤。③ 5–9 s——那一刻：亮度从盆沿向盆心退，橙→暗红→陶本色；黑彩最后变黑，人面和两条鱼在冷下来的红陶上一处接一处显出来，停住；火声收掉，只剩陶冷却的细小“嗒”声。④ 9–12 s：火光退成黄土墙，低案出现，盆落在案上，正俯视全貌 = p=1 停留画面。遮画：作品形一直在，只被火色染着，9 s 起干净。
- 那一刻：观众以为在看一团火，火退了，才发现火里一直躺着那张人面。纹样不是贴上去的，是烧出来的。
- 中式美学：泥与火（中国陶瓷的起点）；观物取象：人第一次在自己烧出的器物上取象；俯身看盆里这种观看方式从第一秒就教给观众。
- 可行性：素材：彩陶正俯视图（需图源审计换更大的图）+ 按亮度阈值从原图算出的黑彩遮罩。冷却 = 原图上叠一层按黑体色温曲线变化的发光色，黑彩遮罩延迟变暗；只调色不变形，浏览器 canvas 实时可做。热浪扭曲只做在盆外背景层。俯身用两层平面视差，不做 3D。成本 S–M。
- 风险：发光做成饱和的“CG 熔岩”就廉价，色要按灼热陶器的暗橙；不能在画面或墙文里说“彩原来是别的颜色”（生坯上铁锰彩的实际颜色要核）。不画具体窑形（半坡窑型待核），只有一圈火光。

**B「一根泥条盘成一只盆」**（材料：陶 · 泥条）一根红泥条从案面一圈圈盘上去，盘成盆壁、拍平、入窑：中国艺术的第一根“线”是一根泥条。

- 依据：仰韶文化陶器多用泥条盘筑成型，再拍打、刮抹（通行，半坡具体工艺待核）。
- 编排：① 0–2 s：p=0 门厅收束帧，案上一团湿红泥。② 2–6 s：泥团搓成泥条，俯看它一圈圈盘起，每圈压住上一圈，盆壁升高。③ 6–9 s：陶拍把螺纹拍平，湿泥的暗红被一闪窑火换成烧后的赭红。④ 9–12 s——那一刻：盆壁里侧的人面鱼纹落定（交接到原图），正俯视 = p=1。
- 那一刻：一根泥条自己长成一只盆，节奏一圈圈的，最后一拍盆里突然有了一张脸。
- 中式美学：线的起点（李泽厚“线的艺术”）；彩陶那种一圈圈转的节奏。
- 可行性：泥条盘筑是新做的动画，需离线预渲染（写实 3D 或精细 2D 序列），最后 1–2 s 与原图对位淡入；成本 M–L。
- 风险：做得像陶艺游戏就廉价；生成的盆与原作形必须一致，否则像换图；纹样不能在动画里“画出来”（不编笔顺）。

### 彩陶 → 吉金（`caitao` → `jijin`）· 推荐 A

**A「泥范敲开，吉金是金色的」**（材料：陶范 · 铜）同一种泥做成范、烧硬、合拢、灌进铜水；泥范敲开，里面的鼎是金黄的，三千年后才锈成今天的青黑。

- 依据：商代青铜以陶范块范法铸造：范用精选泥料制成并焙烧，铸后打碎外范取器（通行；安阳孝民屯铸铜遗址出土大量陶范）。青铜为铜锡铅合金，新铸时呈金黄色，铭文称铜为“吉金”，今天的青绿是锈（通行）。
- 编排：① 0–2 s：p=0 彩陶盆停留；镜头从盆沿移到案边一块同色湿红泥（盆不动、不毁）。② 2–5 s：泥块压在一件看不见的模上再揭下，泥面是反向的兽面阴纹（取后母戊鼎真实纹饰的反相，只露一块）；几块范在黑暗里围拢成方形。③ 5–8 s：范被烧成暗红；一线铜水从浇口注入，范缝透出橙光，是全场唯一的光（商厅全馆最暗）。④ 8–11 s——那一刻：泥范按鼎的真实分块一块块敲裂、带着重量落下，露出的鼎是金黄的，兽面在铜水余光里闪，停一拍。⑤ 11–14 s：金色从高处向下均匀“老”成青黑锈色（整件同时变旧，不是溶解），镜头退到正面仰看全形 = p=1。
- 那一刻：所有人心里的青铜都是绿的；泥范敲开那一刻是一只金色的鼎，“吉金”两个字当场被看懂。
- 中式美学：铸鼎象物；商的狞厉：黑暗、火、重；纹样从“画上去”变成“铸出来”；与上一厅同是泥与火，一冷（陶冷却）一热（铜熔化）。
- 可行性：鼎用现有 3380×4400 照片（需确认原件）；“金色版”= 同一照片调色（亮度保持、色相映到新铜色、高光轻提），不重画不变形；泥范是按鼎外形生成的几块范壳，离线预渲染（有重量的碎裂与下落），最后与照片对位；铜水和火光 canvas。成本 M。遮画：8–11 s 的金色版本身就是作品形，11 s 后回原色。
- 风险：范的分块若是规则方格 = “矩形分块显现”（底线）：必须按鼎的真实结构分（四面、四角沿扉棱、底、耳），有重量地落。金色不能做成电镀金光（和西方厅“金底”撞），要偏暗的新铜色。若入场也选“窑火”，两次火相邻：本方案只留铜水的光、不出现窑，或入场换 B。

**B「全形拓：一张纸上拍出一只鼎」**（材料：纸 · 墨 · 拓）一张白纸蒙上去，拓包一下下扑墨，一只鼎的形和纹从黑里“拍”出来；揭开纸，后面站着真的鼎。清代文人就是这样把青铜“看”到纸上的。

- 依据：全形拓是清代金石学的传拓技法，把立体青铜器拓在一张纸上再题跋成轴（通行，创始人如六舟待核）；本地已有后母戊鼎全形拓（PD，见 halls 图源栏）。
- 编排：① 0–2 s：p=0 彩陶停留；盆里黑彩与红底被推成只剩两块颜色。② 2–5 s：画面成了一张白纸，纸下有看不见的起伏（纸面受光有凹凸）。③ 5–9 s——那一刻：拓包一下下扑，沉而慢，每下一声闷响，鼎的轮廓、扉棱、兽面从墨里显出，是全形拓原件的像素。④ 9–12 s：纸从一角揭起（平面卷起），纸后的黑暗里是鼎的照片，火光从下方起。⑤ 12–14 s：拓纸移到一侧作并挂，鼎正面 = p=1。
- 那一刻：拓是中国独有的显影：不靠光，靠手一下下拍出来，而且显出来的是真拓片。
- 中式美学：金石气；“摩挲钟鼎，亲见商周”（赵希鹄）：中国人怎样看青铜。
- 可行性：用全形拓原图做显影遮罩（拓包落点序列离线定好，每下扩一片软边区域，按拓片自身明暗顺序先显凸处）；浏览器实时；揭纸为 2D 卷起。成本 S–M。
- 风险：每下都是圆斑就成了“斑块溶解”——要用拓包的软边和“凸处先上墨”的真实顺序；彩陶→拓纸一步联系弱（只有黑与底），属视觉型。

### 吉金 → 秦俑（`jijin` → `qinyong`）· 推荐 A

**A「字从鼎腹落到陶工身上」**（材料：铜 → 陶 · 铭与戳）鼎腹里铸着“后母戊”，是给祖先的名字；镜头出来时铜变成了灰陶，同一个位置上压着的是一个陶工的名字。

- 依据：“后母戊”三字铸于鼎腹内壁（halls）；秦俑身上多有陶文戳印或刻文，记工匠之名，与“物勒工名，以考其诚”（《礼记·月令》，已核 verify_facts：目的是追查质量）相合。具体用哪一处陶文、怎么释读，prep 时按秦陵博物院资料定。
- 编排：① 0–2 s：p=0 鼎正面停留。② 2–5 s：镜头按原本的看法探进鼎口，贴着内壁找到“后母戊”三字，停一拍。③ 5–9 s——那一刻：字的位置不动，四周的铜色换成灰陶的颗粒质感（局部材质交叉），三字换成一枚陶文戳印（真实照片淡入同一位置），停住，无声。④ 9–13 s：后拉，戳印所在是一尊俑的甲片或衣摆，俑身出现；再后拉成一号坑一列列军阵 = p=1（俯瞰）。
- 那一刻：同一个位置，神和祖先的名字换成了做它的人的名字：字的主人换了。
- 中式美学：从铸鼎象物的神圣到“事死如事生、物勒工名”的秩序；铜与陶两种物质的交接。
- 可行性：需要清楚的秦俑陶文照片（秦陵博物院或 Commons，待图源）和鼎腹铭文图（无实拍就用铭文拓本过渡）；材质交叉只在铭文周围一小块；后拉用俑身特写与坑阵两图尺度匹配淡接（非 3D）。成本 M。
- 风险：两张照片尺度对不上就像拼贴；要选戳印在显眼位置且有高清全身照的一尊俑；鼎腹铭文实拍可能缺。

**B「一个模子，八千张脸」**（材料：陶 · 模）块范是一个模子铸一件；秦人把“模”用到了人身上：同一副头模压出粗胎，再一只只用手刻出不同的眉眼。

- 依据：秦俑头部多以合模制粗胎，再手工塑刻五官细部，形成“千人千面”（通行，工艺细节待核秦陵博物院）。
- 编排：① 0–2 s：p=0 鼎停留。② 2–5 s：铜色褪成素陶色，镜头落到一副两半的头模（新做的示意）。③ 5–9 s：模合上、打开，一张没有表情的粗胎；刀刻、按压出一撇胡子、一道眉，随即换成一张真实俑脸照片；再合、再开，又一张不同的真脸（3–4 张，节奏渐快，像鼓点）。④ 9–12 s——那一刻：最后一次打开，镜头拉起，眼前是成排的脸，停住。⑤ 12–14 s：俯瞰坑阵 = p=1。
- 那一刻：模子一开一合的节拍像秦的鼓点；从“一样”到“每一张都不一样”。
- 中式美学：秦的审美：整齐、重复、写实；制度化的生产。
- 可行性：需 3–4 张光线相近的真实俑头像（Commons 多 CC BY-SA）；模与刻塑为新动画需预渲染。成本 M–L。
- 风险：真脸一张张跳出有拼盘感；刻塑做成软泥揉捏就是“橡皮变形”——只用刀刻、按压这种硬手法，或只做模开合 + 换真脸。

### 秦俑 → 帛画（`qinyong` → `bohua`）· 推荐 A

**A「封在地下的颜色」**（材料：漆 · 白膏泥 · 木炭 · 朱砂）秦俑身上的彩一见空气就卷起剥落；这一片彩往下落，穿过黄土、白膏泥、木炭，落进马王堆的黑暗里：那里的颜色两千年后还像新的。

- 依据：秦俑彩绘以生漆为底层，出土后失水卷曲、很快脱落（通行，“几分钟内”待核秦陵博物院）；马王堆一号墓椁外填木炭、上下封白膏泥，密封使帛画色彩保存完好（通行，数量待核湖南博物院）。
- 编排：① 0–2 s：p=0 坑阵停留。② 2–5 s：推到一尊俑衣上真实残彩的位置，彩片边缘翘起、卷曲、脱离（生漆层成卷剥落的样子，不是粒子）。③ 5–9 s：它往下落，镜头跟着穿过横向地层：黄土 → 灰白的白膏泥 → 黑的木炭（每层真实材质，≤4 s）。④ 9–11 s——那一刻：落进黑暗，下方亮起帛画最下端的地下世界，朱、青如新，停住。⑤ 11–15 s：镜头沿帛画自下而上：墓主人间 → 天门 → 日月，退开见 T 形全幅 = p=1。
- 那一刻：前一秒是“颜色在眼前死掉”，下一秒是“两千年前的颜色还活着”；颜色能不能留下，靠的是泥和炭。
- 中式美学：汉代“飞动”的上升：自下而上读三界，是引魂升天的方向；朱与黑；事死如事生。
- 可行性：需要带真实残彩的俑近照（或二号坑绿面跪射俑，待图源）；剥落为单片卷曲薄片的预渲染；地层用真实黄土、白膏泥、木炭照片纹理（待找）；帛画上行是纵向窗口（3329×4804）。上行速度 ≤1/7 屏高/秒，15 s 内只够走约 1.5 屏高，可让上行延续进停留。成本 M。
- 风险：剥落做成粒子飞散就廉价；地层段拖长就是“串朝代却没有信息”（墙文要讲白膏泥与木炭）；与秦俑厅展项“抢救彩绘”同题，二者互为呼应或只留一个。

**B「四重棺，一层层开」**（材料：漆）从俑身那层黑漆底出发，打开马王堆的四重漆棺：黑漆素棺、黑地彩绘棺上的云气神怪、朱地彩绘棺，最里面锦饰内棺上盖着的就是帛画。

- 依据：马王堆一号墓为四重套棺，自外而内黑漆素棺、黑地彩绘棺、朱地彩绘棺、锦饰内棺，T 形帛画覆于内棺盖上（通行，待核湖南博物院）。
- 编排：① 0–2 s：p=0 坑阵停留。② 2–4 s：推到俑身剥落处露出的黑漆底，黑漆铺满屏。③ 4–10 s：黑漆原来是第一重棺盖，整块向一侧滑开（刚体、有重量）；下面是黑地彩绘棺，云气纹里的小神怪在飞（原图，镜头缓慢横过）；再滑开，朱地彩绘棺的红一闪；再滑开——④ 10–12 s——那一刻：锦面上平躺着帛画，停住。⑤ 12–15 s：帛画从平躺立起挂上墙（一次平面旋转）= p=1。
- 那一刻：一层黑、一层云气、一层朱，像拆一个越拆越亮的盒子；楚汉的朱与黑八秒里全过一遍。
- 中式美学：漆的朱与黑；楚汉浪漫的云气与飞动。
- 可行性：需四重棺正俯视照片（湖南博物院官方图或 Commons，待图源）；棺盖滑开是整张照片刚体平移，不切块。成本 M。
- 风险：四张照片连闪像拼盘；斜拍透视会穿帮，只能用正俯视图，找不到就用 A。

### 帛画 → 兰亭（`bohua` → `lanting`）· 推荐 A

**A「丝换成了纸」**（材料：绢 → 纸）帛画的绢在镜头里散回一根根丝；一张竹帘从水里抄起一张纸；第一笔落下，是“永和九年”。写字的底子从丝换成纸，字才能随手写给自己。

- 依据：汉代书写多用简帛，东晋时纸已通行，桓玄下令以黄纸代简（《初学记》引《桓玄伪事》，通行待核）；兰亭神龙本为纸本（halls）。何延之《兰亭记》称右军用“蚕茧纸、鼠须笔”（通行，蚕茧纸是何物有争议，只作“据传”）。
- 编排：① 0–2 s：p=0 帛画 T 形停留。② 2–5 s：推进帛画空白处的绢面到经纬可见（用真实绢纹理，不放大原图），经纬松开成一缕缕丝。③ 5–8 s：丝落进一池清水；一张竹帘从水下抬起，水从帘缝滴落，帘上留下一层湿白的纸（抄纸，俯看，真实水面）。④ 8–11 s——那一刻：纸干成淡米色，墨笔按神龙本笔顺写出第一行“永和九年”，停住。⑤ 11–14 s：后拉，通篇在长案上 = p=1。
- 那一刻：抄纸那一下，水面下抬起一张纸，是很多人没见过的中国工艺；第一行字就写在这张刚出水的纸上。
- 中式美学：魏晋“韵”：轻、不费力；材料更替让字成了一个人的心迹。
- 可行性：绢纹理已有；抄纸需预渲染（有 CC 许可的抄纸实拍视频更好）；写字按原迹遮罩 + 人工标注笔顺预渲染（look §1.6，一行约 1 h）。成本 M–L。
- 风险：纸不是丝做的：画面里“丝散开、纸抄起”是材料更替的象征，墙文要讲清，或把丝段改成“绢退场、麻纤维入水”；笔顺错是底线级错误；抄纸段 ≤4 s。

**B「太阳落成一方半印」**（材料：朱砂 · 印泥）帛画右上角那轮红日沉成一片朱，落到兰亭卷首成了半方“神龙”印；这卷字就是因这方印得名“神龙本”。

- 依据：神龙本因卷首有唐中宗“神龙”年号半印而得名（通行，待核故宫页）；帛画右上为红日与金乌（halls）。视觉 + 史实。
- 编排：① 0–2 s：p=0 帛画停留。② 2–5 s：镜头上行到右上角红日（原图）。③ 5–8 s：红日的朱色像印泥一样“沉”成一片无形的朱，帛画淡成纸色。④ 8–10 s——那一刻：这片朱由神龙半印的形淡入落定（原图像素），停住。⑤ 10–14 s：向左后拉，经过前隔水上的收藏印，通篇 = p=1。
- 那一刻：从天上的太阳到纸边的一枚印；观众第一次注意到手卷边上那些红印是有来历的。
- 中式美学：印章与朱砂；“画的历史写在它自己身上”。
- 可行性：需要含前隔水半印的神龙本高清图（Commons 4513×1480 是否含半印待核）。成本 S。
- 风险：圆日变方印若做成形变就是“橡皮变形”：只能是朱色沉淀后由印形淡入；视觉型为主。

### 兰亭 → 洛神（`lanting` → `luoshen`）· 推荐 A

**A「游丝」**（材料：墨线 · 纸 → 绢）行书字与字之间那根细细的牵丝叫“游丝”；顺着它往左走，纸换成绢，它成了洛神飘起的衣带。后人把顾恺之的线也叫“游丝描”。

- 依据：张彦远《历代名画记·论顾陆张吴用笔》由张芝、王献之“一笔书”说到陆探微“一笔画”，“故知书画用笔同法”（通行待核原句）；评顾恺之“紧劲联绵，循环超忽”（已核 S8）。“高古游丝描”为明代“十八描”之一，以顾恺之为代表（通行，出处待核）。
- 编排：① 0–2 s：p=0 兰亭通篇停留。② 2–5 s：镜头移到两字之间一根清楚的牵丝（prep 选一处），沿笔势走过它，停一拍，竖排小字“游丝”。③ 5–9 s：丝不断，延出纸边继续往左（新画的一笔，匀、细、慢，墨色同原迹），脚下纸色渐暖成绢色，纸纹换成绢纹。④ 9–11 s——那一刻：这根线落进洛神的衣带，与原画衣带线严丝合缝，洛神在这一段回眸，停住。⑤ 11–14 s：长案上洛神一臂宽落定 = p=1。
- 那一刻：观众亲眼看到“书画用笔同法”：同一根线，前半是字，后半是画，中间没断。
- 中式美学：书画同源；骨法用笔（线的艺术）；晋人的“韵”在线里。
- 可行性：连接的一笔用真实毛笔笔触扫描预渲染，终点对齐洛神衣带线（人工标路径）；两卷在同一张长案上，镜头只左移（4 s 约 0.5 屏宽，在速度上限内）。洛神停留窗口定在第一次出现洛神那段。成本 M。
- 风险：连接笔像矢量线就假；落点对不准就是拼贴。“游丝描以顾恺之为代表”是后人归纳，墙文写“后人称”。全馆“一根线接两件作品”只用这一次。

### 洛神 → 九色鹿（`luoshen` → `jiuselu`）· 推荐 A

**A「土红起稿，粉脸变黑」**（材料：泥壁 · 土红 · 铅颜料）洛神的墨线换成土红，落在一面抹了白灰的泥壁上；画工填上矿物色和西来的晕染，然后十秒里过去一千五百年，粉红的脸一张张变黑，成了今天 257 窟的样子。

- 依据：敦煌壁画以土红线起稿（通行）；北朝人物用“凹凸法”晕染，源自天竺（许嵩《建康实录》记张僧繇“凹凸花”“乃天竺遗法”，通行待核）；肤色晕染所用含铅颜料年久变色发黑，是北朝壁画人物“黑脸”的成因（通行，敦煌研究院有研究，具体颜料待核）。
- 编排：① 0–2 s：p=0 洛神一段停留。② 2–5 s：长案和绢退去，一面粗泥壁从暗里出现，抹上一层白灰；一根土红线勾出一个人形（示意人物，与 257 窟一个真实人物同形）。③ 5–8 s：填石绿、土红，脸和身上一圈粉红晕染。④ 8–11 s——那一刻：时间加速，粉红晕染由边向里变暗、变黑，只剩眼白、鼻梁一道白；镜头退开，这正是 257 窟西壁那一排人的样子（原图），停住。⑤ 11–14 s：窟内暗，光从门口一侧来，横带在西壁落定 = p=1。
- 那一刻：很多人以为敦煌人物本来就是黑脸；看着它从粉红“老”成黑，才知道时间也在画这幅画。
- 中式美学：佛陀世容（北朝）；外来晕染与中国线条相遇；壁画的材料：泥、白灰、土红、矿物色。
- 可行性：示意片段需预渲染（写实颜料质感），并与 257 窟一个变黑明显的人物严格同形，变黑后交叉到原图；原图 6496×1114 约 1.5×，退开段够用。成本 M–L。
- 风险：最大风险是编造原来的颜色：粉红必须依据敦煌研究院已发表的研究或数字复原，否则退成“一块颜料样片”变黑的演示，不做人形；墙文写“据研究”。洛神→壁画的交接要短。

**B「一卷铺成一面墙」**（材料：绢 → 泥壁）手卷是右往左一段段看的；到了北魏，故事画满一整面墙，要从两头往中间走。

- 依据：洛神赋图为手卷连续叙事；257 窟九色鹿为横卷式壁画，从两端向中间讲，高潮在正中（halls，待核敦煌研究院）。
- 编排：① 0–2 s：p=0 洛神停留。② 2–5 s：卷筒不收，两端同时展开，这条横带越铺越长直到两端出屏，绢色暗成土红泥壁色。③ 5–9 s：长案沉下去，横带竖起贴上岩壁（平面刚体），四周黑下来成了窟；横带内容在运动中换成九色鹿壁画。④ 9–12 s——那一刻：两端各亮一小段（溺水人 / 王后），镜头从两头往中间走，停在正中鹿王对国王。⑤ 12–14 s：横带全貌 = p=1。
- 那一刻：同一种连环画读法反了方向：你不再动卷，得自己走。
- 中式美学：异时同图；石窟的观看方式。
- 可行性：纯版式动作，浏览器可做；两端段落坐标预先定。成本 S–M。
- 风险：内容替换那一步像换幻灯片，要藏在刚体运动中间；发现感一般。

### 九色鹿 → 卢舍那（`jiuselu` → `lushena`）· 推荐 A

**A「石头决定了佛」**（材料：砾岩 → 石灰岩 · 凿）莫高窟的崖是卵石胶结的砾岩，一凿就打滑，所以只能泥塑、画壁；龙门的石灰岩细密坚硬，一凿咬进去，就能刻出十七米高的佛。

- 依据：莫高窟开凿于砾岩崖体，岩质不宜雕刻，故以彩塑、壁画为主；龙门开凿于石灰岩，宜于雕刻（通行，待核敦煌研究院、龙门石窟研究院表述）。
- 编排：① 0–2 s：p=0 窟内壁画停留。② 2–5 s：镜头平移出壁画边（不在画上动），到一处泥皮剥落的角落，露出砾岩：卵石、粗砂（真实岩面照片），油灯光在卵石上抖。③ 5–8 s：一记凿声，凿子落在卵石上，崩开、打滑，刻不动。④ 8–11 s——那一刻：第二记凿声，岩面换成细密的灰白石灰岩，凿痕干净，一道弧形衣纹被凿出来；上方打开天光（从窟里走到露天），停住。⑤ 11–15 s：镜头沿衣纹往上抬，经胸到卢舍那的脸，再退成全龛仰视 = p=1。
- 那一刻：两记凿声，一记打滑、一记咬进石头，观众用耳朵就懂了：为什么敦煌是画，龙门是刻。
- 中式美学：因材施艺；北魏的超然（暗窟）→ 唐的亲近（露天晨光）：佛陀世容由清瘦到丰满。
- 可行性：需莫高窟砾岩与龙门石灰岩的岩面近照（Commons，待图源）、卢舍那衣纹近照与全龛（Gary Todd CC0）；凿痕 = 沿衣纹路径推进的遮罩，不做 3D。成本 M。
- 风险：换岩面要在凿子落下一瞬遮住（像凿开了表层），否则像溶解；上抬到脸要慢（≤1/7 屏高/秒），时间不够就让上抬延续进停留。

**B「光明遍照」**（材料：光）窟里只有门口那一点光；走出窟口，太阳从伊河对岸升起，正照在卢舍那的脸上。“卢舍那”的意思就是光明遍照。

- 依据：奉先寺大龛坐西朝东、面向伊河，清晨阳光正对佛面（halls）；“卢舍那”意为光明遍照（通行）；孟子“充实而有光辉之谓大”（halls，通行）。
- 编排：① 0–2 s：p=0 窟内停留，光从门口斜进。② 2–6 s：门口的光越来越宽，窟壁退向两边，像人往外走。③ 6–9 s：外面是清晨的冷天光，低处一线暖色从画外（观众身后）升起。④ 9–12 s——那一刻：暖光自下而上爬上佛脸（两张不同光照的真实照片交叉），琵琶一声，停住。⑤ 12–14 s：全龛 = p=1。
- 那一刻：从黑窟走到晨光里，一张脸被太阳点亮，而朝向是造像时就定好的。
- 中式美学：盛唐气象：充实而有光辉。
- 可行性：必须有晨光下拍摄的真实照片才做“光上脸”，不在作品上画光（DESIGN-RULES §5）。成本 S–M。
- 风险：接近西方式光影戏剧；只有用真实朝向与真实照片时才成立，否则放弃。

### 卢舍那 → 溪山（`lushena` → `xishan`）· 推荐 A

**A「佛退场，山站出来」**（材料：石 → 墨点）镜头从卢舍那的脸继续往上抬，越过龛顶，是龙门西山的崖；崖上的麻点一颗颗落成绢上的墨点。到了北宋，山自己成了主角，人小得像芥子。

- 依据：北宋山水取代人物成为主科（李泽厚 9.2，halls）；“雨点皴”因点如雨点得名（通行）；两件都是仰看（halls：卢舍那仰望、溪山高远）。以视觉联系为主，史实在“皴是画家写石头的办法”。
- 编排：① 0–2 s：p=0 全龛仰视停留。② 2–5 s：镜头继续上抬（与仰视同方向），越过龛楣，到龛上方西山的崖壁（同一张全龛照片上部，或另一张崖照）。③ 5–9 s：崖面风化的麻点处，墨点从上往下一颗颗“落”下来，石色退去，绢的暗褐从底下透上来。④ 9–12 s——那一刻：墨点密成一整面崖，范宽主峰的峰顶先露（原作像素），停住。⑤ 12–14 s：镜头下行到山脚驮队（看到人有多小），退成全轴装裱挂墙 = p=1。
- 那一刻：同一次抬头，前半看见佛，后半看见山：佛走了，山留下。
- 中式美学：三远·高远；北宋“无我之境”；皴法（墨点代替颜色）。
- 可行性：需要全龛照片上方有足够崖壁（待核），否则另找西山崖照；落墨 = 用范宽雨点皴区域的真实墨点像素作遮罩，按从上往下的顺序显；范宽原图 11105×24176 余量大。成本 M。
- 风险：“石点变墨点”若像噪点叠化就是底线问题：必须是有方向、有节奏的“墨点落下”，点就是原作的点。

**B「一场雨落成雨点皴」**（材料：雨 · 墨点）伊河上落了一场雨，雨点打在石头上一个个洇湿；雨停，湿痕留在绢上，成了范宽的雨点皴。

- 依据：雨点皴得名于形似雨点（通行）；“师造化”（halls）。视觉型。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：雨声先到，屏上落下细雨丝（半透明细线，快过）。③ 5–9 s：镜头转到龛旁石面，雨点打湿处一个个变暗叠起，石色退成绢色。④ 9–12 s——那一刻：雨停，湿点不干，成了墨点，拉开已是范宽的崖，停住，只剩溪声。⑤ 12–14 s：全轴 = p=1。
- 那一刻：全馆唯一一场雨；声音从佛前的琵琶换成雨，再换成溪。
- 中式美学：皴法；北宋的雄强与湿润。
- 可行性：雨丝 canvas 实时；湿点显现同 A。成本 S–M。
- 风险：雨遮画 2–5 s，要细、要快；不能做成烟雨迷蒙（那就成了雾）。与 A 二选一。

### 溪山 → 汴京（`xishan` → `bianjing`）· 推荐 A

**A「从仰看到俯看：以大观小」**（材料：立轴 → 手卷）沈括笑李成把亭馆飞檐画成“仰看”，说山水要“以大观小，如人观假山”；立轴从墙上放倒到案上，观众从仰看一座山变成俯看一整座城。

- 依据：沈括《梦溪笔谈·书画》“李成画山上亭馆及楼塔之类，皆仰画飞檐……大都山水之法，盖以大观小，如人观假山耳”（通行，待核原文）；故宫称《清明上河图》采取“散点透视法”（已核，content_e3）。
- 编排：① 0–2 s：p=0 溪山全轴挂墙停留。② 2–5 s：挑杆取下立轴，画沿地杆向后倒平（一次平面倾倒，≤60° 透视压缩，不翻转），视角从仰变俯，墙成了案面。③ 5–8 s：立轴自下而上卷回天杆，案上留一条空的长案；左边一卷新手卷落下、解带。④ 8–11 s——那一刻：手卷向左展开到虹桥一段，人潮和船从上方俯看，停住，竖排一行“以大观小”。⑤ 11–14 s：两卷筒定位、案沿出现 = p=1（虹桥窗口）。
- 那一刻：观众的身体跟着变：一秒前在抬头，一秒后在俯身看一张桌上的城。
- 中式美学：三远 → 以大观小（散点透视）；立轴是竖向的空间，手卷是横向的时间。
- 可行性：纯引擎动作：平面倾倒 + 卷起（look §2.3 A 卷筒算法）+ 手卷展开；清明图已校色。成本 S–M。前提：汴京停留窗口定在虹桥段。
- 风险：倾倒做成 3D 翻飞就违反 look 反面清单 #10；卷起时不能露出伪造的画背。

**B「驮队下山进城」**（材料：绢）溪山脚下那队驮货的牲口往左走出画边，隔着一段空绢，路尽头是清明上河图卷首驮着木炭的驴队：北宋人从山里走进了城。

- 依据：溪山山脚有驮队（halls）；清明卷首有驮炭驴队走向城（通行解读，“炭”待核）；两队同向（待核原图）。
- 编排：① 0–2 s：p=0 溪山停留。② 2–5 s：镜头下行到山脚驮队（≤1.5×），开始左移。③ 5–9 s：出画边是一段空绢，画幅由竖变横（边框变化，不动画面），案面升起。④ 9–12 s——那一刻：空绢尽头，卷首柳下的驴队正好在同一水平线接上，驴铃一声，停住。⑤ 12–15 s：卷首窗口 = p=1。
- 那一刻：一次不剪的左移，两队牲口在同一条线上接上。
- 中式美学：可行可望可游可居；边走边看。
- 可行性：前提：汴京停留窗口定在卷首（与 A 冲突，也牵动下一处）；两队高度对位。成本 S。
- 风险：空绢不能变成雾；“驮炭”要核；与先导片“骡队走出了山”同源。全馆“同一水平线接上”手法只用一次。

### 汴京 → 汝窑（`bianjing` → `ruyao`）· 推荐 A

**A「一河水烧成了釉」**（材料：水 → 釉）镜头落进虹桥下的汴河，水面慢慢静下来、沉下去，绢的淡褐沉成一汪天青，四周翘起一圈盆沿：宋人把一池静水烧成了釉。

- 依据：视觉型为主。汝窑釉薄处泛粉、积釉处淡碧（halls），像水的深浅；汝窑釉“内有玛瑙末为油”（周煇《清波杂志》，通行待核）；比德于玉（halls）。
- 编排：① 0–2 s：p=0 虹桥窗口停留。② 2–5 s：镜头俯身看汴河（原图水纹），船和人移出画外（镜头动，原图不动）。③ 5–9 s：水面区域的墨线极短时间内淡平，随即被一片由浅到深的天青颜色场覆盖（取汝窑照片实测色）。④ 9–12 s——那一刻：画面四周翘起一圈椭圆盆沿，天青里泛出釉的光泽，窗光从一侧慢慢扫过釉面，停住。⑤ 12–14 s：退开，水仙盆坐在木座上、一侧有窗 = p=1。
- 那一刻：一整条河“静”成一块釉：从最满、最闹的一卷，到最静、只有一种颜色的一件。
- 中式美学：宋人的“平淡”（绚烂之极）；比德于玉的温润。
- 可行性：盆沿 = 汝窑俯视照片外沿遮罩由外往里淡入；柔光扫釉沿用北宋片做法（预渲染光带，soft-light，只在器物遮罩内）。成本 M。
- 风险：“水面变淡”是在原作上处理，必须 ≤1.5 s 并立即被颜色覆盖，否则就是溶解/糊；联系是意象，墙文不写“汝窑模仿河水”。

**B「有芒不堪用」**（材料：釉 · 支钉）虹桥旁食摊上一只白碗，碗口一圈没上釉的“芒”；南宋人记朝廷嫌定窑白瓷有芒，命汝州烧青瓷。汝窑满釉支烧，只在底下留六个芝麻大的钉痕。

- 依据：叶寘《坦斋笔衡》“本朝以定州白磁器有芒不堪用，遂命汝州造青窑器”（陶宗仪《南村辍耕录》引，通行待核）；定窑覆烧致口沿无釉（通行）；水仙盆底六个支钉痕（halls）。
- 编排：① 0–2 s：p=0 虹桥停留。② 2–4 s：镜头移到食摊桌上几只白碗（原图，≤1.5×）。③ 4–7 s：换到一只真实定窑芒口碗的俯视照片，口沿一圈露胎，竖排小字“有芒不堪用”。④ 7–11 s——那一刻：一层青釉从碗心漫开，漫过口沿包住芒；碗翻过来，底下只剩六个支钉痕：正是水仙盆的底（ru_spurs 原图），停住。⑤ 11–14 s：盆翻回正面坐上木座 = p=1。
- 那一刻：一个缺点（芒口）逼出一门工艺（满釉支烧），六个钉痕就是答案。
- 中式美学：宋人格物与精；满釉如玉。
- 可行性：需定窑芒口碗 CC0 俯视图（大都会/克利夫兰待查）；清明食摊白碗是否看得清待核；碗→盆靠“翻过来”的动作遮住换图，不形变。成本 M。
- 风险：三张图有拼盘感；“命汝州造”要核原书。可降级为汝窑展项或墙文。

### 汝窑 → 寒江（`ruyao` → `hanjiang`）· 推荐 A

**A「一色减成一角」**（材料：釉光 → 空白）窗光扫过汝窑釉面，最后只剩一道细细的高光；釉色退去，这道光成了寒江上的几道水纹。北宋把颜色减到一色，南宋把画减到一角。

- 依据：视觉 + 审美链：汝窑一色的“平淡”与南宋“马一角”的留白同属宋人的减法（halls、李泽厚）。
- 编排：① 0–2 s：p=0 水仙盆停留，窗光在釉面。② 2–5 s：光带扫到盆一端，只剩一道横向细高光；天青从四周退成绢的暖灰。③ 5–8 s：盆的轮廓淡出，只剩那道高光；它淡去的同一位置，一道淡墨水纹显出，左右再显两三道（寒江原作像素）。④ 8–10 s——那一刻：水纹中间出现一叶小舟、一个弓身钓鱼的人（原作），其余全空，古琴泛音一声，然后静。⑤ 10–13 s：小幅落定在大片装裱色中央 = p=1。
- 那一刻：一道光变成一条江，而这条江几乎没画；观众自己把空白认成了水。
- 中式美学：留白 · 虚实相生（“无画处皆成妙境”）；宋人从一色到一角的减法。
- 可行性：光带做法已有；水纹 = 寒江原图遮罩从中向两侧显（ColBase 3000×1613 / Commons 5906×3159）。成本 S–M。
- 风险：高光“变成”水纹不能是形变，只是同位置交接；空白太久像卡住，泛音要准时。

**B「盆里的一汪水，放大成一条江」**（材料：釉 → 水）俯看水仙盆，一汪釉色像一池水；一根钓丝垂下，水面一圈涟漪。镜头退开，盆沿不见了，那一池水成了一条寒江。

- 依据：视觉型（以小见大）；两件都是书斋里近看的小东西（halls：把玩 / 小幅近看）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：俯身看盆内底，天青铺满屏。③ 5–8 s：一根极细的墨线垂下，触水处一圈淡涟漪（只在颜色场上）。④ 8–11 s——那一刻：退开，盆沿被装裱边取代，天青褪成绢灰，涟漪中心正是寒江钓丝入水处，舟与人出现，停住。⑤ 11–13 s：p=1。
- 那一刻：一个手上的盆，一退开就是一条江：尺度一下翻过来。
- 中式美学：以小见大；寒江独钓的静。
- 可行性：钓丝落点 = 原图钓丝入水坐标；涟漪 canvas 实时。成本 S。
- 风险：新画的钓丝必须与原作钓丝完全重合；涟漪要极轻。

### 寒江 → 富春（`hanjiang` → `fuchun`）· 推荐 A

**A「同一根线，在绢上是水，在纸上成了山」**（材料：绢 → 纸 · 干笔）寒江的一道水纹被一支干笔接着往左写，绢换成纸，线在纸上擦出飞白，成了富春江边的坡岸。赵孟頫说“石如飞白”：画是写出来的。

- 依据：元代文人画由绢转纸、以干笔渴墨披麻皴写山（halls）；赵孟頫题《秀石疏林图》“石如飞白木如籀……须知书画本来同”（通行，上墙前按原迹核）。
- 编排：① 0–2 s：p=0 寒江停留。② 2–5 s：推到最长的一道水纹（≤1.5×），其余淡成空；装裱色退成纸色，纸纹从绢纹里长出来（只在空白处交叉）。③ 5–9 s——那一刻：一支干笔从这道水纹左端接着往左拖（真实干笔扫描），墨少、笔毛分叉，拖出一道满是飞白的长线，停住，竖排小字“石如飞白”。④ 9–12 s：线上方落几笔长披麻皴，这道飞白线正是富春停留窗口里一条坡岸线（原作像素接管）。⑤ 12–14 s：长案一臂宽 = p=1。
- 那一刻：同样一笔，绢上润、纸上毛；飞白一出，元人的“写”就懂了。
- 中式美学：书画同源；逸笔草草；绢→纸是元人的材料革命。
- 可行性：干笔一笔需真实毛笔干笔扫描预渲染，落点对齐富春停留窗口的坡岸线（前提：富春 IIIF 拼接能到约 1500 px 画心高，待实测；不行按 halls 改挂《秀石疏林图》，本方案照样成立且更贴题）。成本 M。
- 风险：新画一笔要与原作笔性接得上，否则像拼贴；与“丝换成纸”（帛画→兰亭）都讲纸，墙文分开：那处讲写字的底子，这处讲干笔飞白。

**B「最后一个人离开画面」**（材料：绢 → 纸）寒江的钓者是整幅画的主角；镜头离开他往左走，一路是空的水，绢冷成纸，富春江上的小渔舟几乎看不见了。

- 依据：先导片 judge T6 同一逻辑；元“有我之境”（halls）。
- 编排：① 0–2 s：p=0 停留。② 2–6 s：从小舟向左慢移，只有空白，绢暖色冷成纸色，经纬换成纤维。③ 6–10 s：空白里先出一道远山线，再是近处坡岸（富春原作）。④ 10–12 s——那一刻：富春江上一只小渔舟出现在与寒江小舟同样的高度，停住。⑤ 12–14 s：p=1。
- 那一刻：两只小舟在一条线上接上，一个是主角，一个几乎看不见。
- 中式美学：平远；从一角到长卷。
- 可行性：停留窗口需含渔舟（与 A 的坡岸二选一）。成本 S。
- 风险：空白平移 4 s 以上像卡住；与“驮队下山进城”同一手法，全馆只用一次。

### 富春 → 青花（`fuchun` → `qinghua`）· 推荐 A

**A「入窑前是黑的」**（材料：钴 · 窑火）元人画水墨的那种笔，在一只白坯上画龙；钴料上坯时是灰黑的，像墨；一窑火烧过，黑变成了蓝。

- 依据：釉下青花以钴料在生坯上绘画、罩透明釉高温一次烧成；钴料未烧时呈灰黑色，烧后发蓝（通行，烧成温度约 1300°C 待核）；大维德瓶有 1351 年纪年题记（halls）。
- 编排：① 0–2 s：p=0 富春停留。② 2–4 s：推到一块披麻皴，纸的白换成一面微灰的弯曲白坯（瓷坯质感；富春图不形变，是底子换）。③ 4–8 s：坯上一片片显出灰黑的龙纹，像墨（大维德瓶真实龙纹的灰黑版，按龙身走向分区显出）。④ 8–11 s——那一刻：窑火的橙光由下而上漫过全屏一次，火退，灰黑成了钴蓝，坯面有了釉光，停住。⑤ 11–14 s：退开，整只瓶坐在座上 = p=1。
- 那一刻：观众以为在看又一幅水墨，火一过，墨成了青花：两种“蓝与黑”原来出自同一种笔。
- 中式美学：书画同源延伸到瓷上；错彩镂金的满与蓝白强对比；窑火（与第一厅的火首尾相应）。
- 可行性：大维德瓶图 2724×4100（CC BY 2.5）；灰黑版 = 同一图调色（不改形）；显出顺序用手绘区域遮罩（不宣称是真实笔顺）；火光 canvas。成本 M。
- 风险：显出像笔顺动画就会被问依据：做成区域随笔势显出，不做单笔描线；瓶是曲面，显出区域要随曲面。

**B「字写进画，又写上了瓶」**（材料：纸 → 瓷 · 字）富春卷后是长长的题跋，画的历史写在它自己身上；元人还把字写上了瓷：大维德瓶瓶颈写着供养人张文进和至正十一年。

- 依据：富春卷有黄公望自题与后人题跋（halls）；大维德瓶瓶颈纪年题记（halls，待逐字释读）。
- 编排：① 0–2 s：p=0 停留。② 2–6 s：镜头移到画上有字的一段（停留窗口若无字，此方案不成立）。③ 6–9 s：一竖行字停在画面中，纸色暗成深墙色，字行随圆柱面弯成瓶颈的弧（刚体映射）。④ 9–12 s——那一刻：换成瓶颈上真实的青花题记，停住。⑤ 12–14 s：整瓶 = p=1。
- 那一刻：竖排的字从纸上绕到了瓶颈上。
- 中式美学：书画同源、器上写字；题跋。
- 可行性：需瓶颈题记清楚照片（待图源）。成本 M。
- 风险：曲面映射像特效；卷到拖尾太远会晃眼。优先 A。

### 青花 → 写意（`qinghua` → `xieyi`）· 推荐 A

**A「蓝晕开成了墨葡萄」**（材料：钴 → 墨 · 生宣）元青花的钴蓝在釉下常晕开一圈；镜头穿过釉面，那圈晕成了墨在生宣上沿纤维洇开，一颗接一颗，湿叠着半干，成了徐渭的葡萄。

- 依据：元青花钴料在釉下有晕散现象（通行）；生宣吸水、墨沿纤维洇开是纸性；“运墨而五色具”（张彦远，已核 S8）；徐渭题诗“笔底明珠无处卖”（已核 content_e4）。视觉 + 材料现象。
- 编排：① 0–2 s：p=0 瓶停留。② 2–4 s：推到瓶身一处真实的蓝色晕散（≤1.5×）。③ 4–8 s：釉光褪掉，底子换成生宣（真实纹理），蓝转成墨；一滴饱墨落下，沿纤维洇开，边缘毛。④ 8–11 s——那一刻：墨点一颗接一颗，湿的叠在半干上，恰好落在徐渭葡萄的位置；一笔草书般的藤甩过去连住它们，停住，竖排“笔底明珠”。⑤ 11–14 s：墨点交叉到原作像素，退开见全轴 = p=1。
- 那一刻：瓷上的“毛病”和纸上的“神来之笔”是同一种东西：颜料自己跑出了边界。全馆墨最猛的一刻。
- 中式美学：墨分五色；写意（墨自己长出来）；明中晚期的狂与湿。
- 可行性：墨扩散离线模拟（纤维方向用真实生宣扫描），按徐渭原作葡萄位置与形状生成，最后与原作交叉；原作 6432×16303 余量足。成本 M–L。
- 风险：洇墨像模板“墨滴落水”（look 反面 #14）就砸：墨点必须落在原作真实墨位、形状接近原作；青花→生宣一步是视觉型，要短。

**B「龙身一笔甩成老藤」**（材料：线）青花龙纹是画工一笔笔快画出来的；龙身最后一笔甩出瓶外，在纸上成了徐渭那根草书般的老藤。

- 依据：视觉型（笔势连续）；书为心画（halls）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：推到龙身粗细变化明显的一段。③ 5–9 s：一笔新墨线顺势甩出瓶外（真实笔触），底子变生宣。④ 9–12 s——那一刻：这一笔正是徐渭的主藤（原作接管），葡萄一串串垂下，停住。⑤ 12–14 s：p=1。
- 那一刻：一笔从瓶上甩到纸上。
- 中式美学：线的艺术。
- 可行性：需徐渭主藤路径标注。成本 M。
- 风险：与“游丝”同为一根线接两件作品，全馆只用一次，所以 A 优先。

### 写意 → 八大（`xieyi` → `bada`）· 推荐 A

**A「明珠落，白眼开」**（材料：湿墨 → 焦墨）徐渭说他的明珠“闲抛闲掷野藤中”；最低那颗葡萄落下来，在空白里一路下坠一路干，湿墨干成焦墨，落成八大那只鸟朝天的眼珠。

- 依据：徐渭自题诗（已核 content_e4）；青藤→雪个的写意师承（齐白石诗“青藤雪个远凡胎”，通行待核）；八大白眼（halls）；“传神写照，正在阿堵中”（halls，通行）。
- 编排：① 0–2 s：p=0 墨葡萄全轴停留。② 2–4 s：顺藤下行到最低那颗水滴形葡萄。③ 4–8 s：它离开藤（整颗移出，原处用周边纸色补），穿过一大片空白纸下坠；纸从暖白换成八大纸的冷白；墨珠一路变小，边缘由湿晕收成焦墨硬边。④ 8–11 s——那一刻：墨珠落进鸟的白眼圈，停在眼圈顶上，成了朝天的眼珠，停住，箫一声。⑤ 11–14 s：从鸟退开，上方的空纸、荷、石全现 = p=1。
- 那一刻：一颗墨从明代掉进清代，落成一只眼睛的眼神；全馆最满接全馆最空。
- 中式美学：计白当黑（下落穿过的全是空白）；传神阿堵；湿墨与焦墨的材料差。
- 可行性：需最低葡萄单颗抠图（整体移动不变形）与补底；鸟眼坐标人工定（halls 待定）；墨珠“变干”是边缘处理，预渲染。成本 M。
- 风险：近于“漂浮剪影”：全程只允许这一颗墨珠动，要有重力感；补底要干净。先导片用过，网站有墙文承载信息，可重用。

**B「哭之笑之」**（材料：墨 · 字）徐渭在画角题诗，字就是心；八大把“八大山人”四字连着写，有人读作“哭之”，也读作“笑之”。

- 依据：八大署款连写似“哭之”“笑之”（通行说法，多为后人解读，待核）；“书，心画也”（扬雄《法言·问神》，通行待核）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：移到左上徐渭题诗，停一拍。③ 5–9 s：诗行淡回纸里，空纸上按原迹笔顺写出八大署款，四字一气。④ 9–11 s——那一刻：极淡的竖排小字标出“哭之 / 笑之”两种读法，停住。⑤ 11–14 s：从署款的真实位置退到全幅 = p=1。
- 那一刻：一个签名里藏着一个人的态度。
- 中式美学：书为心画、从于心。
- 可行性：《荷石水鸟图》署款清楚（6139×16787）；笔顺人工标注。成本 S–M。
- 风险：墙文写“有人读作”；署款形态因年而异，要用这一件上的实际署款。

### 八大 → 百骏（`bada` → `baijun`）· 推荐 A

**A「同一张白纸：先是线，再是影子」**（材料：纸本白描 → 绢本重彩）八大的鸟站在石上，石下没有影子；同一片白纸上浮出郎世宁《百骏图》的白描稿，一层层染出明暗，最后马蹄下落出一道影子。

- 依据：大都会藏郎世宁《百骏图》白描稿（1991.134，CC0，halls），为此卷画稿（通行，待核大都会说明）；邹一桂评西洋画“阴阳远近……笔法全无”（halls，待核）。
- 编排：① 0–2 s：p=0 八大全轴停留。② 2–4 s：镜头移到石块下方的空白（没有影子的地方），停一拍。③ 4–8 s：空纸上浮出白描稿里一组马的墨线（稿本原像素），只有线。④ 8–11 s——那一刻：纸色换成绢色，马身按原作明暗分 3–4 层依次显出体积，最后蹄下落出投影，停住，马蹄声。⑤ 11–14 s：镜头向左，马群在长案一臂宽落定 = p=1（与稿本对应的一段）。
- 那一刻：同一张白纸，前一刻是没有影子的中国，后一刻是有影子的西洋；两种画法的差别在眼前一层层发生。
- 中式美学：骨法用笔（线先于一切）与阴阳远近相遇；八大的空与清宫的繁两极。
- 可行性：需稿本与原作同段精确对位（构图应一致，待核；不一致就只取单匹马）；“染”= 原作按明暗分层依次显，不加新东西；百骏 16560×2022（1.87×），一臂宽够用。成本 M。
- 风险：对不上会穿帮；原作马下确有投影的位置要核；不自己加影子。

**B「白眼对着一只有高光的眼睛」**（材料：墨 · 光）八大鸟的白眼是态度，郎世宁马眼里那一点白是窗外的光：一样是眼里的白，一个是心，一个是光。

- 依据：八大白眼（halls）；郎世宁以西法画眼中高光（通行）；阮籍“能为青白眼”（《晋书·阮籍传》，通行）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：推到鸟眼（≤1.5×）。③ 5–8 s——那一刻：眼圈里的墨珠与白交叉成一只马眼，眼中一点高光，停住。④ 8–12 s：退开：马头、马身、马群。⑤ 12–14 s：p=1。
- 那一刻：眼对眼的换位，像西方厅“亚当的手→基督的手”。
- 中式美学：传神阿堵 vs 西洋写实。
- 可行性：现有百骏图 2022 px 高，马眼十几像素，推近必糊：只有台北故宫 Open Data 分段图更高清时才可做（待核）。
- 风险：放大到糊（底线）。

### 百骏 → 蛙声（`baijun` → `washeng`）· 推荐 A

**A「画出来的水，不画的水」**（材料：水 → 留白）百骏图里马涉的溪水画得有倒影、有深浅；顺着溪往下，水的颜色一层层退掉，最后只剩两壁黑石夹着一道白纸：齐白石的山泉一笔水都没画。

- 依据：郎世宁以西法画水与倒影（通行，待核原作溪水段）；《蛙声十里出山泉》山涧为留白（halls）；以虚写实（halls）。
- 编排：① 0–2 s：p=0 百骏停留（窗口需定在溪水段）。② 2–5 s：镜头沿溪水往下游移，马留在画外（镜头移出，马不动）。③ 5–8 s：窗口由横幅变竖幅（形状过渡，不旋转画面），溪水的倒影与明暗一层层退，只剩白。④ 8–11 s——那一刻：两壁浓墨石块从两侧显出夹住这道白（原作像素），水里几只蝌蚪往下游，远处一声蛙鸣，停住。⑤ 11–14 s：全轴 = p=1。
- 那一刻：前面把一切都画出来，后面连水都不画；观众靠耳朵听见了画外的十里。
- 中式美学：以虚写实、画外之意；似与不似之间。
- 可行性：蛙声原图 873×3461 只能整幅看（halls），④ 在整幅尺度发生；溪水色场是新过渡层。成本 S–M。
- 风险：横转竖做成旋转会晕；百骏是否有涉水溪段要核；若蛙声换挂《画藤》，本方案改为“画出来的藤 / 金石的藤”，需重写。

**B「从收藏印到自己刻的印」**（材料：印泥 · 石 · 刀）百骏图上盖的是清宫的收藏印；齐白石自称“三百石印富翁”，印是他一刀刀刻的：朱色从“谁收藏了它”变成“谁做了它”。

- 依据：《百骏图》为清宫旧藏，钤清宫收藏印（通行，印文待核台北故宫）；齐白石以篆刻名世，自号“三百石印富翁”（通行）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：移到画上一方清宫收藏印（≤1.5×）。③ 5–9 s：朱色沉下，印面翻成一块石章（印石照片），刻刀单刀冲下，石屑崩开，一道齐白石式刀痕（预渲染）。④ 9–11 s——那一刻：石章按下揭起，是齐白石一方真印的印蜕，停住。⑤ 11–14 s：退到蛙声全轴，这方印在画上的位置 = p=1。
- 那一刻：刀进石头那一声和崩口：金石气是听得见的。
- 中式美学：金石气；印从所有权到创作。
- 可行性：需百骏图清宫印清楚图、齐白石印蜕（中国大陆已公有）；蛙声图小，印在画上只能整幅尺度看。成本 M。
- 风险：蛙声画上那方印是否齐白石自刻要核；与“刻字的手”（蛙声→天书 B）只取其一。

### 蛙声 → 天书（`washeng` → `tianshu`）· 推荐 A

**A「蝌蚪成了读不出的字」**（材料：纸 · 雕版）山泉里的蝌蚪游到纸的尽头；古人把一种谁也读不出的古字叫“蝌蚪文”。下一刻，纸上排满了一行行像字、却读不出的字。

- 依据：《尚书序》（传孔安国）言孔壁古文“科斗书废已久，时人无能知者”，“科斗”因笔画头粗尾细得名（通行，待核原文）；徐冰《天书》四千余个自造“字”无人能读（halls）。
- 编排：① 0–2 s：p=0 蛙声全轴停留，蛙声远远的。② 2–5 s：镜头下行到山泉尽头的蝌蚪（整幅尺度，不推近），蛙声停。③ 5–8 s：纸从齐白石的暖白换成新宣纸的冷白（颜色场）；蝌蚪原地不动，旁边的空白里一枚一枚“字”像雕版印上去一样出现（每个一声轻轻的压印声），竖行。④ 8–11 s——那一刻：一行、两行、满屏，天书的字铺满（原作页面像素），停住，全静。⑤ 11–14 s：后退，页面成了装置里的一本书、一面墙 = p=1。
- 那一刻：画里看不见的蛙，你听见了；这里满眼的字，你却读不出。蝌蚪和“蝌蚪文”的双关是真的古代说法。
- 中式美学：言不尽意，立象以尽意；字本身的“象”。
- 可行性：天书图源小（工作室 ≤1354 px），满屏字用整页图的逐行显现遮罩，不把字剪下来拼。成本 S–M。
- 风险：蝌蚪不能动（动了就是漂浮剪影）；墙文说清是双关，不说“天书来自蝌蚪文”。

**B「刻字的手」**（材料：木 · 刀 · 墨）齐白石的印是反着刻的，按下才是正字；徐冰也一刀刀反刻了四千多个木活字，印出来，却谁也不认识。

- 依据：篆刻与活字都需反刻（常识）；《天书》“字”为徐冰手刻活字（通行，halls）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：移到画上一方印（整幅尺度），印的朱色扩成一片颜色场（不放大原图）。③ 5–9 s：朱换成墨，出现一枚木活字的反字（实拍或预渲染），刻刀修最后一刀，上墨。④ 9–11 s——那一刻：活字压纸、揭起：一个像字却不认识的字，停住，无声。⑤ 11–14 s：后拉，一行行铺满 = p=1。
- 那一刻：揭起那一下的“认不出”。
- 中式美学：金石、刻；字的形与义分离。
- 可行性：需木活字实物照片。成本 S–M。
- 风险：与“从收藏印到自己刻的印”只取其一；与 09-27 草稿相同。

### 天书 → 尾声（`tianshu` → `coda`）· 推荐 A

**A「卷的年轮」**（材料：纸 · 绢 · 卷）天书的最后一页纸成了这卷长卷的拖尾；整座展厅从当代卷回新石器，卷紧后，卷端的截面是一圈圈“年轮”，最外一圈是陶红。

- 依据：视觉型；手卷看完从尾卷回，卷首重回外层（halls 尾声，收卷方向待核装裱行规）。
- 编排：① 0–2 s：p=0 天书装置停留。② 2–5 s：一页宣纸落到长案上成了拖尾，最右端还留着入场时按下的那方馆印（呼应入场）。③ 5–10 s：长卷从左往右收（卷筒真实地转），卷面掠过的只是一段段材料：宣纸白、清宫绢、冷白纸、生宣、元纸、宋绢、窟壁土红、漆黑、铜绿、陶红（材料色与纹理，不闪回作品）。④ 10–13 s——那一刻：卷收紧，镜头转到卷端，截面是十九圈层，由内到外从当代到新石器，最外一圈是陶红，停住。⑤ 13–15 s：包首合上、系带，签条“中国艺术的演变” = 尾声停留画面（盖观款在此）。
- 那一刻：一卷画的截面像一棵树的年轮，一眼看到“演变”。
- 中式美学：手卷即时间；看完就卷，下次再展。
- 可行性：卷筒算法沿用 look §2.3 A；材料带用各厅墙纹理（部分待找）；截面同心环 canvas。成本 M。
- 风险：材料带混进作品图就成了“拼盘回顾”；“年轮”只是画面，墙文不写。收卷方向要核。

**B「最初的刻，最后的刻」**（材料：陶 · 刻）天书的字一行行淡回纸里，只剩一个；镜头回到最初的红陶口沿，那里刻着一道符号，有学者认为与汉字起源有关。最早的刻痕和最后的刻字，都读不出。

- 依据：半坡陶器口沿刻划符号（halls 彩陶作品栏；与汉字起源的关系为学者一说）。
- 编排：① 0–2 s：p=0 停留。② 2–5 s：字一行行墨色变淡回纸（慢、均匀），只剩一个。③ 5–9 s：纸色变成红陶，这个字的位置出现一道真实的刻划符号，竖排小字“有学者认为……”。④ 9–12 s——那一刻：退开，这片口沿属于一只陶器，放在长案上，旁边是收起的整卷，停住。⑤ 12–15 s：尾声停留画面。
- 那一刻：首尾扣上：从刻一个记号，到刻四千个不能读的字。
- 中式美学：立象以尽意；首尾回环。
- 可行性：需刻划符号高清图（待图源）。成本 S。
- 风险：必须写“有学者认为”；字变淡要避免“墨迹擦除”模板感。

## 三、方案之间的依赖与搭配（选的时候要一起看）

- **停留窗口要先定**：p=1 必须等于本厅停留画面，下一处的 p=0 从同一画面出发。本视角推荐方案需要：汴京停留在**虹桥段**（溪山→汴京 A、汴京→汝窑 A/B 都从这里）；洛神停留在**第一次出现洛神、回眸的那段**；富春停留窗口要含**一条长坡岸**（寒江→富春 A 落点、富春→青花 A 起点）；百骏停留窗口要**与大都会白描稿对得上、并含溪水段**（八大→百骏 A、百骏→蛙声 A），两者若不在同一窗口，要在停留期间的自动卧游里解决；卢舍那停留用**全龛含龛上崖壁**。
- **溪山→汴京**：A（以大观小，落虹桥）与 B（驮队，落卷首）互斥，B 会改变汴京停留窗口并牵动下一处。
- **火别扎堆**：入场 A（窑火冷却）+ 吉金 A（铜水）相邻两处都有火，一冷一热，可以当对照；嫌重复就入场改 B，或吉金改 B（全形拓）。青花 A 的窑火隔得远，没关系。
- **同一手法全馆只用一次**：“一根线接两件作品”只给兰亭→洛神 A（所以青花→写意取 A 不取 B）；“同一水平线接上”在溪山→汴京 B 与寒江→富春 B 里只能选一处；“刻”在百骏→蛙声 B 与蛙声→天书 B 里只能选一处。
- **与展项同题**：秦俑→帛画 A（彩绘剥落）与秦俑厅展项“抢救彩绘”同题，可以当作故事的前后两半（厅里你救，转场里它还是落了、而汉代的颜色被泥和炭留住了），嫌重就换展项。
- **图源决定生死的方案**：八大→百骏 B（马眼太小，现有图必糊）、卢舍那 B（要有晨光实拍）、秦俑→帛画 B（要四重棺正俯视图）、汴京→汝窑 B（要定窑芒口碗 CC0 图）。这些找不到图就不做。

## 四、特别展项（每厅一个）

标准照荡秋千：有物理手感，能亲手玩，会给反馈；原作始终挂在墙上，展项在复制品或另一件实物照片上玩；不做说明性开关和图表。

### 彩陶（`caitao`）· `coil_and_fire`

案上一团红泥：按住拖着画圈，泥条从手下一圈圈盘上去；画圈半径决定盆壁外撇还是内收，速度忽快忽慢泥条会断。盘够高后点按“陶拍”拍打，拍得匀盆壁光整，太重会拍凹一块。最后推进窑里，盆在火光里由橙红冷成赭红，厚薄不均处“嗒”一声开裂。墙上的人面鱼纹盆始终在，你烧好的盆摆在它旁边的案上。

- 手感与反馈：泥条有粘性和重量，跟手有一点滞后；拍打有闷响和回弹；冷却时陶的细碎“嗒嗒”声。做坏了也好看（一只歪盆），可以再来。
- 亲身感到：泥与火；有意味的形式来自一圈圈的节奏

### 吉金（`jijin`）· `piece_mold_casting`

几块泥范按边缘吸附合拢（合不严会漏铜）；拖动坩埚倾倒铜水，铜水有重量和粘度：倒太急起气孔，太慢半途凝住“浇不足”；冷却后逐块敲开泥范，露出金黄的鼎；拖动一根“年代”绳，金色慢慢锈成墙上那件的青黑。

- 手感与反馈：坩埚的倾角有惯性；铜水的光是全厅唯一的光；敲范是一下下有反弹的重击，碎范带重量落地。失败有真实的铸造缺陷（气孔、缺角），不是分数。
- 亲身感到：铸鼎象物；吉金本是金色

### 秦俑（`qinyong`）· `save_the_paint`

一尊刚出土的俑（单独的一张真实照片，不是墙上坑阵），表面残彩的位置按原物，彩在空气里开始翘起：拖动“喷壶”在它表面走，喷到的地方彩停止卷曲、定住，来不及的一片片卷起落下。每次结果不同，结束时把你保住的彩和墙上原物对照。

- 手感与反馈：喷洒有扩散范围和持续时间；彩片卷起有细小的“簌簌”声；一两分钟的紧张节奏。卷曲过程按秦陵保护研究的描述做示意，墙文写“示意”。与秦俑→帛画转场 A 同题，二选一或互为呼应。
- 亲身感到：秦的写实原本是有颜色的；为地下造的东西见了光就开始消失

### 帛画（`bohua`）· `raise_the_banner`

画面下方一根竹竿系着帛画的复制品：向上拖竿把它举起，绢有重量，会摆；举得越高，自下而上依次露出地下、人间、天上；举稳了，顶上的日月才看得清，四角的穗在风里飞。用途写“学者认为”。

- 手感与反馈：布料模拟（重量、摆动、阻尼），举太快会甩、会缠；风声随高度变大。原作始终竖挂在墙上。
- 亲身感到：汉代的飞动与上升；自下而上读三界

### 兰亭（`lanting`）· `floating_wine_cup`

曲水流觞：一只漆耳杯（造型取马王堆“君幸酒”漆耳杯）顺弯曲的溪水漂下，碰岸、打转、被水推走；拖动水面改变水流。杯停在谁面前，谁就作诗，揭示那人当天成诗与否（兰亭诗人数与罚酒传说待核才写）。

- 手感与反馈：水流场 + 杯的惯性和阻尼；杯碰石头有轻响；停住的那一刻有一拍安静。
- 亲身感到：魏晋的韵：不费力、随机、雅集

### 洛神（`luoshen`）· `silk_thread_line`

在一段空绢上拖一支笔画一根长线：速度稳、压力匀，线就细而连绵，同时响起一个持续的古琴泛音；手一快线变细、一抖线起毛，泛音就断。画完的线自动和旁边洛神衣带上顾恺之的一根原线并排比较。

- 手感与反馈：笔有墨量和摩擦，绢面有轻微阻力；声音就是反馈：线匀，声就长。
- 亲身感到：骨法用笔；春蚕吐丝的线

### 九色鹿（`jiuselu`）· `oil_lamp_cave`

暗窟里拖一盏油灯照壁，灯照到的地方才显色；灯移太快火苗会歪、变暗，要慢慢走。故事要从两头往中间照，才照得到正中鹿王与国王那一幕。把灯拉远，壁上的晕染看起来鼓出来；贴近看，又是平的（出自《建康实录》记张僧繇的“凹凸花”，待核）。

- 手感与反馈：火苗有惯性和摇晃，影子跟着灯走；窟里有回声和滴水；灯油会慢慢减少，照到正中时正好快灭。
- 亲身感到：气韵生动；凹凸晕染“远望眼晕如凹凸，就视即平”

### 卢舍那（`lushena`）· `chisel_drapery`

一块石灰岩：一手扶凿（拖动定角度），一手按节奏敲锤（点按或空格）。节奏稳、角度对，凿子沿衣纹一路咬进去，刻出一道干净的弧；敲乱了会崩一块。刻完的一道衣纹和墙上卢舍那的衣纹对照。

- 手感与反馈：像荡秋千一样靠节奏：拍子对上，凿得越来越深；石屑、粉尘、锤声的音高随深度变。
- 亲身感到：因材施艺；唐的衣纹饱满、流畅

### 溪山（`xishan`）· `hang_the_scroll`

用一根叉竿把卷起的立轴挑上高处的挂钩（《长物志》“悬画宜高”），竿头要稳，挑歪了轴会滑下来；挂上后松手，地杆带着重量往下放开，画一路展开、摆几下停稳，惊燕轻轻飘。挂好后可以凑近山脚树丛，找藏在叶间的“范宽”二字（李霖灿 1958 年发现，待核）。

- 手感与反馈：叉竿有长度和杠杆感；展开时画轴的重量、摆动和最后的静止；挂钩“嗒”一声。
- 亲身感到：悬画宜高；高远

### 汴京（`bianjing`）· `rainbow_bridge`

先搭虹桥：把一根根木梁按编木拱的方式交错搭上（放对了互相咬住，放错了拱会下沉、吱呀作响）；搭成后一队驮炭的驴走过，桥微微一沉。随后一条大船顺急流冲来：一手放桅（拉绳，有重量），一手撑篙；放晚撞桥，放早船打横，桥上人群喊声随危险变大（依据原作虹桥段）。

- 手感与反馈：木梁的重量与咬合、木头的吱呀；绳的张力；水流推船的力。两段都能玩，也都能失败重来。
- 亲身感到：宋人格物；卧游里的市井

### 汝窑（`ruyao`）· `celadon_kiln`

把盆坐上支钉放进匣钵、入窑：按节奏拉风箱升温，到了高温关小烟囱闸门（还原）；开窑时颜色由你的火决定：米黄、豆青、月白、天青（示意，墙文写明）。出窑冷却时釉面“叮、叮”地开片，裂纹一路走；最后翻过来看底，六个支钉痕。墙上那件是少见的无纹之作（通行说“唯一”，待核）。

- 手感与反馈：风箱有来回的阻力和呼吸般的节拍；窑火颜色随温度变；开片的清脆声是这一厅最好听的声音。
- 亲身感到：平淡、如玉；天青来自火里的还原

### 寒江（`hanjiang`）· `cast_into_blank`

拿过渔人的竿，往画上的空白里抛线：钓丝入“水”处泛起涟漪，涟漪在空白里一圈圈扩开，碰到看不见的岸再弹回来，你才知道这条没画出来的江有多宽；等一会儿，线会被轻轻拽一下。

- 手感与反馈：竿有弹性，抛线要甩；涟漪极淡、极慢；拽线时竿梢一弯。只在展项模式里画在复制品上，退出即消失。
- 亲身感到：留白 · 虚实相生：空白自己成了水

### 富春（`fuchun`）· `rejoin_the_scroll`

把《剩山图》那一段拖过去，靠近无用师卷的断口时有吸附，烧痕和山势对得上才“咔”地合上（1650 年火中一分为二，2011 年两段在台北合展）；合上后可以展开看卷后的题跋。若核实卷着烧的焦痕按卷径重复，再加一步：把纸卷紧、点火、展开看烧痕的间距。

- 手感与反馈：纸有重量和弹性，边缘对齐靠手感；合上那一下有纸与纸的轻响。
- 亲身感到：手卷的聚散；画的历史写在它自己身上

### 青花（`qinghua`）· `cobalt_on_raw_clay`

一只白坯在轮上转（拖动旋转，有惯性），把笔贴上去画：钴料是灰黑的；画完入窑，烧出来才变蓝。蘸料太厚的地方烧出黑斑和晕散，太薄发灰。烧好的瓶和墙上大维德瓶并排。

- 手感与反馈：转坯的惯性和笔尖的摩擦；入窑前后颜色的反转是这一厅的“揭晓”。
- 亲身感到：错彩镂金；器上写画

### 写意（`xieyi`）· `ink_bloom_grapes`

毛笔在生宣上按住不动，墨随时间沿纤维洇开，按得越久葡萄越大越湿；湿墨点在半干的墨上会出一圈水线（破墨）；快速一甩，甩出带飞白的藤。

- 手感与反馈：墨的扩散是实时模拟，边缘毛；每一下都不同，没有对错。
- 亲身感到：墨分五色；写意

### 八大（`bada`）· `stubborn_white_eye`

拖着立轴的地杆左右晃，画像钟摆一样摆（复制品）；鸟眼里的墨珠像一颗小珠子随重力在白眼圈里滚来滚去，但不管你怎么晃，它最后总会滚回眼圈顶上，朝天翻着白眼。

- 手感与反馈：画轴有重量和摆动阻尼；墨珠有滚动的惯性；每次回到顶上都有一声箫。原作始终不动地挂在墙上。
- 亲身感到：从于心；白眼朝天的孤傲

### 百骏（`baijun`）· `drag_the_sun`

拖动画面上方的一点日光，几匹马的投影随之转动、伸缩（预先算好的投影层，有惯性和阻尼）；松手后投影淡去，马回到“中国画没有影子”的样子。

- 手感与反馈：太阳有拖拽的重量；影子的变化连续、柔和；马蹄声随光移动。
- 亲身感到：阴阳远近 vs 骨法用笔

### 蛙声（`washeng`）· `stir_the_spring`

手指在山涧的空白里搅动，水流带着蝌蚪顺流而下（流场 + 群游，复制品上）；水越急，远处的蛙声越响、越近；你看不见蛙，但听得见。

- 手感与反馈：水的阻力与惯性；蛙声随流速实时变化，停手后慢慢平息。
- 亲身感到：画外之意；以虚写实

### 天书（`tianshu`）· `movable_type_press`

从字盘里取木活字（有重量、吸附）排进版框，滚筒上墨，铺纸压印，揭起：印出来的字个个像汉字，却一个都不认识。也可以拼偏旁：偏旁按真实结构规律吸附，拼出来的都不是真字。

- 手感与反馈：木块的重量与碰撞声；滚墨要匀，压印要按住，揭纸要慢。
- 亲身感到：言不尽意；字的形与义

### 尾声（`coda`）· `collector_seal`

选一方印，蘸印泥（点几下决定印泥多少），按下（按的时间和力度决定印文虚实），慢慢揭起；印落在拖尾里入场时那方馆印之后。

- 手感与反馈：印泥的粘、按压的回弹、揭起时纸被带起一点；印文虚实每次不同。
- 亲身感到：画的历史写在它自己身上；观众成为最后一个观看者

## 五、对照底线自查

- **拼贴 / 切块**：没有把画切成块移动；泥范、棺盖是真实的整块材料，按真实结构分块、带重量；唯一移动的原作元素是“明珠落”里的一颗墨珠（已标风险）。
- **橡皮变形**：圆日变方印、高光变水纹、石点变墨点都写明“同位置交接、不形变”；泥塑只用刀刻按压。
- **斑块溶解 / 矩形分块**：拓包显影、落墨点都要求有方向、按原作自身明暗或墨点顺序显，不用随机圆斑。
- **放大到糊**：凡推近处都标了 ≤1.5×；马眼方案因此标为不可行。
- **剧透下一件**：各方案在“那一刻”之前只露材料（泥、丝、纸、坯、釉色），下一件作品的形在那一刻才出现。
- **串朝代没信息**：每处过渡段都对应一句能上墙的事实（吉金、白膏泥、抄纸、土红起稿、砾岩、以大观小、有芒、石如飞白、钴料、科斗书……）。
- **移动太快 / 遮画太久**：平移按 look 的 1/7 屏宽/秒；每处写了作品被遮的时段，大多在 3–5 s 内。
- **雾**：0 次。

## 六、要核的事实（上墙或上画前）

半坡彩陶烧成温度与黑彩成分；陶范焙烧与“吉金”释义；秦俑陶文实例与彩绘剥落时间；马王堆白膏泥与木炭、四重棺；桓玄以纸代简、“蚕茧纸”；神龙半印；张彦远“书画用笔同法”原句、“高古游丝描”出处；敦煌土红起稿、铅颜料变黑、《建康实录》凹凸花；莫高窟砾岩与龙门石灰岩；沈括“以大观小”原文；清明卷首驮炭；周煇“玛瑙末为油”、叶寘“有芒不堪用”；赵孟頫“石如飞白”原迹；钴料未烧呈灰黑、烧成温度；元青花晕散；齐白石“青藤雪个”诗；八大署款“哭之笑之”；郎世宁白描稿与原作对应；《尚书序》“科斗书”原文；手卷收卷方向。
