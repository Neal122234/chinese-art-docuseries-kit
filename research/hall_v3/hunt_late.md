# 中国厅 v3 · 干净图搜寻（明—近现代）

2026-09-30。标准＝持矛者（Mia 86.6）：纯色无缝背景、均匀棚灯、整件入画、无玻璃/标签/杂物、长边 ≥2400。缩略图全部在 `cand/<slug>.jpg`，都已亲眼看过（总览 `sheet_late.jpg`，第一格为持矛者）。像素：克利夫兰取 API 宽高，大都会用原图文件头实测，台北故宫取 IIIF info.json 最大尺寸。

## 结论

- 本时段器具非常好找：大都会 / 克利夫兰 / 台北故宫的棚拍都是灰或黑的渐变无缝背景加柔光，和持矛者、库罗斯同一路。**40 件候选（器具 33、书画 7）里 A 级 37 件、B 级 3 件**，每个器具门类都有 ≥2 件 A。
- 台北故宫的图是 3055×2291（约 700 万像素，CC BY 4.0），比克利夫兰（4000–13000 px）小，但达到 ≥2400 的要求。每件的**首张（PAA）带标尺和编号标签**，要改用 PAB 以后的角度；本表选的都是不带标签的那一张。
- v2 的**各种釉彩大瓶（北京故宫）不合格（C）**：游客隔玻璃拍的，暗展厅、反光。北京故宫这件查不到馆方开放大图。建议用台北故宫**洋彩玲珑转旋瓶**（23 个角度，可做转动展项）代替它来代表"乾隆极繁"；也可以用克利夫兰的粉彩双耳瓶。
- 翠玉白菜、肉形石：台北故宫馆方灰底图 2292×3054，A 级（都带原配座，属于玉石雕刻，不是实用器）。
- v2 标"白底"的 Met 黄花梨官帽椅实际是灰底，A 级。

## 书画补充（本时段）

- **唐寅《王蜀宫妓图》**（北京故宫，Commons 8556×15868，PD）：唐寅最有名的工笔人物，A。
- **文徵明《寒林古木图》**（Old Trees by a Wintry Brook，克利夫兰 1997.102，1551，2675×6555 CC0）：A。
- **沈周《海棠图》**（Flowering Crab Apple，克利夫兰 1997.101，3336×9900 CC0）、**唐寅《听琴图》**（克利夫兰 1977.199）、**罗聘《钟馗醉扶图》**（克利夫兰 1959.185，扬州八怪）：都是 A。
- 近现代：Commons 有潘天寿立轴 2575×7000（标 PD，题名和收藏地待核，B）。齐白石的虾、黄宾虹、傅抱石、徐悲鸿《奔马》在 Commons 和四家开放图库都没找到高清图。版权实情：齐白石 1957 年卒，黄宾虹 1955 年卒，徐悲鸿 1953 年卒，傅抱石 1965 年卒，潘天寿 1971 年卒，在中国大陆都已进入公有领域（作者去世后 50 年）；美国对 1929 年以后发表的作品可能仍有保护。下一步只能去北京画院、徐悲鸿纪念馆、故宫"名画记"的网页图里找。
