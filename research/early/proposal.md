# 中国艺术的演变：整厅方案（草案）

2026-09-27 · 方案 JSON：`research/plan_draft.json`（16 厅 + 尾声）。所有图源只核实了元数据，没有下载；标“待核”的事实上墙前都要先核实。

## 一、一座馆，两个大展厅

**推荐结构（structure.md 方案 A）**
- `art-in-motion.pages.dev/` 改成**门厅**，西方厅搬到 `/west/`，中国厅放在 `/china/`。现有老链接不会失效，打开后先到门厅，要多点一次。两个展厅各自构建、各自导出，最后由馆级 deploy 合进同一个 dist。
- **门厅**：左右两列，各厅等距排开，不按真实年代比例画（按比例画西方近现代会挤成一团）。同一时期的厅之间用细墨线相连；下方一条年份尺，拖动一方镇纸（有惯性，会吸附到厅的边界），两边对应的厅会亮起来。点哪一厅就直接进哪一厅，深链接写成 `#房间id`，两个展厅的引擎都要加这个功能。
- **两厅互通**：阅读面板末尾加一行“同一时期 · 西方：巴洛克 →”，数据由门厅构建时自动算出。两边的尾声都加一个“去另一个展厅”的入口。两个展厅是两个页面，**不能做跨展厅的连续转场**。
- **跨馆联系**（sound_and_links.md B 表）只写进文字，不做成转场：艾未未《葵花籽》对景德镇瓷，《程氏墨苑》里刻的利玛窦西洋版画，得胜图在巴黎刻版，马克·托比跟滕白也学毛笔。“影响”与“相似”要分开写。
- **防护**：`art-history/deploy/deploy.sh prod` 必须改成调用馆级部署脚本，不然照老办法跑一次，会把整个站点覆盖成只剩西方厅。
- 进入中国厅的方式是“按下一方印”，对应西方厅的“点亮火光”。

## 二、主线与展厅清单

**主线：从器物上的纹样和文字，到纸上的笔墨与心迹，最后回到一个读不出的字。**
器（1–5：泥、铜、陶、绢，做给神、祖先和死者）→ 笔（6–8：字和画成了个人的心迹）→ 山水（9–12：从画院到文人，画变成“写”出来的）→ 我与世界（13–16）→ 尾声。

每厅的展项依次是：慢轮画彩、块范浇铸、拓、拼俑、举幡、展开一卷、曲水流觞、一笔墨写到干、赶骡队找范宽、虹桥放桅、吹水、合璧、笔底明珠、一盏太阳、十里蛙声、排一版天书、盖印。

**被砍掉、只写进作品栏的**：龙门大佛（放在兰亭和祭侄之间找不到过硬的联系，而且会打断“第一、第二行书”这对呼应）、《韩熙载夜宴图》、石涛、八大、瓷器。
**手卷厅**：画卷、汴京、南渡、元人、中西这五个厅用 structure.md C1 的“长案横带”挂法。停留时画卷自动从右往左慢慢展开，下方有一条全卷缩略条；p = 0 取离开上一厅那一刻的画面快照。立轴厅（帛画、山水、写意、蛙声）用纵向窗口，加简化装裱。

## 三、第一批与样板厅

- **第一批：彩陶、吉金、金文、秦俑。** 四件都是器物，不依赖手卷引擎，现在就能开工。开工同时并行做引擎：手卷挂法、竖排、装裱、按一方印入场、深链接。
- **样板厅：吉金。** 它的转场是全方案最“物质”的一段（泥 → 火 → 铜水 → 敲开泥范），可以用来检验中国质感。展项块范浇铸的物理手感最接近秋千。用户认可以后再铺开。
- **第二个样板（手卷）：汴京。** 等引擎的手卷挂法做好后就做，用来检验“骡队走出山”的横移和手卷交接，这是整个馆技术风险最大的一项。

## 四、要你拍板的

1. **网址**：推荐根目录做门厅，西方厅在 `/west/`，中国厅在 `/china/`。代价是老链接打开先看到门厅，要多点一次。另一个做法是西方厅留在根目录，中国厅放 `/china/`，门厅放 `/lobby/`。
2. **命名**：馆名是否沿用“艺术的演进 / Art in Motion”，两个展厅各叫什么（暂定“西方艺术”“中国艺术的演变”）。门厅里哪一边在左。
3. **版权期作品和缺图的厅**：齐白石《蛙声》（中国已公版，美国可能仍受保护）和徐冰《天书》（© 徐冰工作室）都**还没找到可用的高清图**。照挂的话，要允许从馆方或工作室网页取图。找不到时的替补：蛙声换成北京画院藏的虾或蟹图；天书这一厅并进尾声。
4. **第 14 厅“中西”的衔接最弱**：徐渭和郎世宁之间没有真实的联系。两个办法：接受目前这版（新单元的手法作用在上一件作品上），或者加一个石涛厅（变成 17 厅 + 尾声），用石涛“搜尽奇峰打草稿”接郎世宁留下的真草稿。
5. **要不要加瓷器厅或石窟厅**：目前 16 厅里没有瓷器，也没有石窟。加的话建议放汝窑水仙盆（放在汴京之后）和卢舍那大佛，但这两处现在都还没有过硬的转场联系。
