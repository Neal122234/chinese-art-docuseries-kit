# 中国美学理论 → 先导动画的设计规则

用途：「中国艺术的演变」先导动画（60–120 秒，逐帧渲染，1080p/4K，配乐）的气质与设计依据。
怎么读：第 1 节定每一段的气质；第 2 节是可以直接照做、可以验收的规则；第 3 节是禁区。
标记：引号内是原文，后附出处，编号见文末「来源」。**〔设计值〕**是我据原理推出的起点，不是古人说的，要在样片上调。**〔待核〕**是还没找到可靠出处的通行说法，上画布前要核。

---

## 0. 总纲：六句话

1. **一切运动都是一笔。** 起笔有顿，行笔有势，收笔回锋，停下来要稳。镜头、墨、字幕、音乐都按这个节奏走。依据是蔡邕《九势》的"藏头护尾，力在字中"[S10]，以及姜夔《续书谱》记米芾的"无垂不缩，无往不收"[S11]。
2. **空白是画的一部分。** "虚实相生，无画处皆成妙境"，"有画处多属赘疣"（笪重光《画筌》[S6]）。宗白华说"以虚为虚，就是完全的虚无；以实为实，景物就是死的"，只有化实为虚，才"有无穷的意味"[S13]。
3. **视点是游动的，没有灭点。** 宗白华："流动着飘瞥上下四方，一目千里，把握全境的阴阳开阖、高下起伏的节奏"；中国画家用"以大观小"，从全体来组织部分[S12][S13]。
4. **时间领着空间走。** 宗白华："我们的宇宙是时间率领着空间，因而成就了节奏化、音乐化了的'时空合一体'"[S12]。李泽厚讲中国建筑时也说，平面铺开的群体"已把空间意识转化为时间进程"[S1·3.3]。落到动画里，就是手卷式的横向行进，每走一段停一口气。
5. **墨就是颜色。** "运墨而五色具，谓之得意。意在五色，则物象乖矣"（张彦远《历代名画记》[S8]）。整片以墨和纸（绢）为主调，颜色只在它自己的时代出现：青铜的锈绿、汉漆的朱黑、唐的青绿、印泥的朱。
6. **静里出动，动归于静。** "无我之境，人惟于静中得之。有我之境，于由动之静时得之"（王国维《人间词话》[S7]）；宗白华说"深沉的静照是飞动的活力的源泉"[S12]。所以每个"那一刻"前后都留安静。

## 1. 各时代的审美核心（按李泽厚《美的历程》各章）

李泽厚原句均按《美的历程》逐节核对[S1]；章节号写成"章.节"。《美的历程》只写到明清，当代一行是我补的。

| 段 | 审美核心（一两句） | 代表"物质" | 代表"动作"（动画里演什么） |
|---|---|---|---|
| **龙飞凤舞**（新石器彩陶） | "由再现(模拟)到表现(抽象化)，由写实到符号化"，美就是"积淀了社会内容的自然形式"，也就是"有意味的形式"[1.3]。仰韶、马家窑的几何纹"由动物形象的写实而逐渐变为抽象化、符号化"[1.3]。 | 陶土；赭红和黑的矿物彩；窑火 | **写实的形一步步简化成纹样**（鱼 → 几何带），绕器身转一圈。线条第一次独立出来。 |
| **青铜饕餮**（商周） | "一种神秘的威力和狞厉的美"。"它的神秘恐怖正是与这种无可阻挡的巨大历史力量相结合，才成为美——崇高的"[2.1]。同时汉字发展成"线的艺术"，其美"在它们的曲直适宜、纵横合度、结体自如，布局完满"[2.2]。 | 青铜（铸造的范线、铜绿锈、凹凸的纹）；甲骨和金文 | **铸**：液态变凝固，纹样中轴对称地"长"出来，形成重压。线条从刻（甲骨）到铸（金文）。节奏沉、慢、重。 |
| **先秦理性精神** | 儒道互补。建筑"平面铺开、引向现实的人间联想"，"把空间意识转化为时间进程"[3.3]。 | 木构、夯土、群体院落；竹简 | **一进一进地展开**，空间让位给行进的时间。这就是手卷语法的源头。 |
| **楚汉浪漫主义** | "力量、运动和速度，它们构成汉代艺术的气势与古拙"，"不事细节修饰的夸张姿态和大型动作"，"粗轮廓的整体形象的飞扬流动"[4.3]。 | 漆（朱与黑）；画像石、画像砖的拓片；帛画 | **飞扬、速度**：只取粗轮廓的剪影式整体，一个动作一口气完成。拓印本身就是一种材料逻辑（墨从凹凸里显出形）。 |
| **魏晋风度** | "人的觉醒"，即人对自己生命、意义、命运的重新发现[5.1]；"药、酒、姿容、神韵"加上文采，构成魏晋风度[5.2]。书法"把线的艺术高度集中化纯粹化"，从魏晋开始自觉。梁巘《评书帖》说"晋尚韵"[S14]。张彦远评顾恺之的线："紧劲联绵，循环超忽……意存笔先，画尽意在"[S8]。 | 纸、行书墨迹（唐摹本）、绢本人物长卷 | **一笔行书的潇洒**：连绵、轻、不费力，笔断意连。人物线条匀细连绵（紧劲联绵）。 |
| **佛陀世容**（北朝到宋） | 北魏"秀骨清相、长脸细颈、衣褶繁复而飘动"，"以洞察一切的睿智的微笑为特征"，身边的壁画却是悲惨世界[6.1]。唐代"以健康丰满的形态出现"，"更多的人情味和亲切感"[6.2]。宋代"世俗场景大规模地侵入了佛国圣地"[6.3]。 | 石窟岩壁、彩塑、壁画矿物色（有时间剥落与变色） | **一张脸从超然变得亲近**：清瘦到丰满，神变成人。光不要打成西方式的戏剧光，改用岩壁上颜料层的时间：剥落，显出底层。 |
| **盛唐之音** | "青春、自由和欢乐"；诗和书的"审美实质和艺术核心正是一种音乐性的美"[7.2]。张旭、怀素的狂草"流走快速，连字连笔，一派飞动"[7.2]。颜真卿（安史之乱后成熟）代表"新的艺术规范……以树立可供学习和仿效的格式和范本"[7.3]；即"唐尚法"[S14]。 | 纸上狂草；楷书碑；青绿山水 | **狂草一气写下**：速度、连绵、节奏就是本身。随后是颜楷的"立"，一笔一画站定。这一段可以最快，但仍然要有收笔。 |
| **韵外之致**（中唐到北宋文人） | 司空图："近而不浮，远而不尽，然后可以言韵外之致耳"[S15]。苏轼"追求的是一种朴质无华、平淡自然的情趣韵味"，有一种"人生空漠之感"[8.3]。即"宋尚意"[S14]。 | 纸、行书手卷（如《寒食帖》）、淡墨 | **淡与退**：墨变淡，节奏放慢，余味比画面长。字写完之后，停留时间要长于书写时间。 |
| **宋元山水意境 · 北宋"无我之境"** | "客观地整体地描绘自然"；"采取散点透视，不固定在一个视角……不重视诸如光线明暗、阴影色彩的复杂多变"，追求"可游可居"[9.2]。范宽"远望不离坐外"[9.2]。 | 绢；雨点皴的密墨；巨嶂式全景 | **一座山正面立起来**：高远的仰视，满幅的墨一层一层积出来。人很小，不抒情。 |
| **· 南宋"细节忠实和诗意追求"** | 画院追求细节真实和诗意；"马一角"的山水"画面大部份是空白或远水平野，只一角有一点点画，令人看来辽阔无垠而心旷神怡"[9.3]。 | 绢；大面积空白；水、雾 | **退到一角**：画缩到一个角落，空白成了主体。 |
| **· 元"有我之境"** | 以倪瓒为代表："逸笔草草，不求形似，聊以自娱耳"。"笔墨可以具有不依存于表现对象（景物）的相对独立的美"，"书法这时与绘画密切结合起来"[9.4]。题款的位置也在变：唐人藏在石隙树根处，宋人"一线细楷……决不使之过分侵占画面"[9.4]，元以后诗文题跋进入构图。 | 纸（不再是绢）；干笔、渴墨、侧锋；题跋 | **干笔擦出来**：笔枯，墨少，笔锋在纸纹上留下飞白。字和画在同一张纸上平起平坐。 |
| **明清文艺思潮** | 市民文艺 → 浪漫洪流（李贽的"童心"，"个性解放思想"）[10.2] → 感伤。绘画上，八大那种"睁着大眼睛的翠鸟"和"傲岸不驯、极度夸张的形象"，底下"深藏着的孤独、寂寞、伤感与悲哀"[10.4]。石涛"夫画者，从于心者也"[10.4]。工艺（瓷器）到了顶点，但"其趣味倾向与上述绘画和文学的进步思潮，则是恰好相反的"[10.4]。 | 纸；泼墨、大写意；印章与题跋叠满；瓷 | **一画**：石涛"一画者，众有之本，万象之根"[S5]，一笔立起一个世界。八大：极少的笔墨加一只白眼。瓷器可以作为这一段的"物"，但它的繁缛不能成为整片的审美。 |
| **（延伸）近现代到当代** | 李泽厚未写到。唯一可用的古典桥梁是石涛的"笔墨当随时代，犹诗文风气所转"[S16]。 | 看所挂的作品 | 由选作品的那一组决定。**不要**再给当代套"意境、留白"的古典腔。 |

**几条贯穿全片的线**（写转场时可以用，都有出处）：
- **线的接力**：彩陶的抽象纹（1.3），青铜的金文（2.2），魏晋书法的自觉（5.2），盛唐狂草（7.2），元代书法入画（9.4）。李泽厚把书法和山水画都归到"线的艺术"。这是整片最硬的一根脊梁。
- **书风四字**：晋尚韵，唐尚法，宋尚意，元明尚态（梁巘《评书帖》[S14]）。四段书法的节奏可以直接由这四个字决定（见 2.2）。
- **山水三境**：无我（北宋），细节与诗意（南宋），有我（元）（9.2–9.4）。三段的构图、材料、笔法各不相同，一目了然。
- **题款的位置在变**：唐藏款，宋一线细楷，元题跋入画（9.4）。所以字幕的位置本身就能表示时代（见 2.4）。

## 2. 可执行的动画设计规则

### 2.1 构图

**留白比例**〔设计值；依据：笪重光、宗白华、马远"大部份是空白"〕
- 全片每一个停留帧，空白（纸或绢的底色，墨色 L* 在底色 ±5 以内的区域）**不少于 40%**。
- 南宋一段不少于 65%，元代（倪瓒式）一段不少于 55%。
- 北宋全景是有意的例外，可以满（"巨嶂"），但顶部要留天、底部要留水口，空白不少于 20%。
- 实测方法：对停留帧取 L*，统计 |L* − 底色 L*| < 5 的像素比例，写进时间轴验收。
- 空白不许"补东西"：不加祥云、粒子、光斑、飘字。有画处多属赘疣[S6]。

**主体位置**
- 不居中。重心放在对角线的一端，另一端是空白，形成呼应（与"引首章—压角章成对角之势"是同一原理[S17]）。
- 竖幅（挂轴）的比例按装裱的规矩：天头长于地头约五分之二[S18]。画面里出现挂轴时，天头和地头的比例约为 1.4–1.7 : 1（一种常见做法是天头 2 尺、地头 1.2 尺[S19]）。

**三远变成镜头运动**（郭熙《林泉高致·山水训》[S2][S3]）
原文："自山下而仰山颠，谓之高远；自山前而窥山后，谓之深远；自近山而望远山，谓之平远。高远之色清明，深远之色重晦，平远之色有明有晦。高远之势突兀，深远之意重叠，平远之意缥缈。"

| 远 | 镜头 | 色调要求（直接取自原文） | 适用段 |
|---|---|---|---|
| 高远 | **纵向上移**（tilt up / 挂轴自下而上"读"）：从山脚的行旅走到主峰，不做 3D 仰拍透视，画面始终是正面的平面 | "清明"：提高明度，降低墨层的覆盖 | 北宋（范宽） |
| 深远 | **层层推进**：前景（树、石）以平面层的方式向两侧移开，露出后面的山，一层接一层；不能用 3D 景深推进（dolly） | "重晦"：每过一层，墨加深一档 | 北宋全景、五代 |
| 平远 | **横向慢移**（手卷式从右往左），视平线低，远处渐淡到纸色 | "有明有晦""缥缈"：近浓远淡，远山淡到接近底色 | 南宋、元（倪瓒一河两岸） |

**散点透视代替单点透视镜头**
- 视点"流动着飘瞥上下四方"[S13]，也就是"以大观小"[S12]。所以**禁止**真实透视的摄影机：没有灭点，没有广角畸变，没有景深虚化（焦外），没有推近时的透视放大。
- 允许的运动只有两种：**平移**（横向或纵向，读卷）和**正面缩放**（整个平面等比放大缩小，相当于人走近一幅画）。视差只能在几个平面层之间做平移，而且层与层的相对位移要小（≤ 层宽 3%〔设计值〕），近于"移步换景"，不能做成"飞进山里"。
- 手卷从右往左展开，一次看"一臂之宽"（exhibit-kit THEMES）。镜头移动的方向和展卷的方向一致。

**可行可望可游可居**
- 郭熙："山水有可行者，有可望者，有可游者，有可居者"，而可游可居胜过可行可望[S2]。李泽厚据此说中国建筑和山水都是"可游可居"的[3.3][9.2]。
- 落实：镜头行进时，沿画中的**路**走（小径、桥、舟、行旅），停在画中的**居处**（亭、屋、舟中人）。停留帧的落点优先选画里有人、有屋的位置，因为那是画家给观者留的座位。

**四时**（郭熙："春山澹冶而如笑，夏山苍翠而如滴，秋山明净而如妆，冬山惨淡而如睡"[S3]）
- 若全片要有一条季节或时间线，就按这四个字配墨色和彩度：春"澹冶"（淡、微暖），夏"如滴"（湿，墨最润），秋"明净"（干、清、对比稍高），冬"惨淡"（灰、低彩、留白最多）。季节是可选的第二条线，不要与朝代线打架。

### 2.2 运动：气韵落到缓动与节奏

"气韵生动"是谢赫六法之首（"六法者何？一、气韵生动是也；二、骨法用笔是也；三、应物象形是也；四、随类赋彩是也；五、经营位置是也；六、传移模写是也"[S4]）。宗白华把它解释为"生命的节奏"或"有节奏的生命"[S12]。下面把它拆成可以写进代码的参数。

**一笔的三段**（所有有方向的运动都用：镜头、墨线、字、卷轴、印章）
依据《九势》："藏锋，点画出入之迹，欲左先右，至回左亦尔"；"藏头，圆笔属纸，令笔心常在点画中行"；"护尾，画点势尽，力收之"；"疾势""涩势"[S10]；以及"无垂不缩，无往不收"[S11]。

| 段 | 物理 | 缓动写法〔设计值，30 fps 计〕 |
|---|---|---|
| **起笔（藏锋）** | 先向反方向轻顶一下，顿住（"欲左先右"），再出发 | 反向位移为行程的 2–4%，用 3–5 帧；然后静止 2–4 帧（顿）；再出发。镜头起步也这样：不能从 0 直接线性加速。 |
| **行笔（中锋）** | 匀，但不是机械的匀；有"疾"有"涩"，像逆水行舟 | 主体速度近于常数（中段 60–80% 的时间里，速度波动在 ±15% 以内），叠加 1–2 次低频的涩（减速 10–25%，每次 4–8 帧）。**不要**全程 easeInOutSine，那样没有骨。 |
| **收笔（回锋）** | 到头略过，回收，力收在里面 | 冲过终点 1–3% 后回到终点，用 4–8 帧；然后**静止**。回锋之后的静止至少与起笔的顿一样长。 |

- **提按 → 粗细**：线宽随速度反向变化（慢则按、粗；快则提、细），起笔和收笔处最粗。转折处先顿再转（"转笔，宜左右回顾"[S10]）。
- **飞白**要由物理产生：笔上的墨量随行程递减，速度越快、墨越少、纸纹越粗，就越容易露白。不许贴飞白纹理，也不许用"笔刷"素材。
- **按书风定节奏**（梁巘"晋尚韵，唐尚法，宋尚意，元明尚态"[S14]）〔设计值〕：
  - 晋（行书）：连绵，轻，段与段之间"笔断意连"。停顿短（2–4 帧），几乎不完全静止。
  - 唐（狂草 → 颜楷）：狂草是全片最快的一段，一气写三到五个字，中间不停，最后一笔长收。颜楷每一笔单独起收，笔间停顿 6–10 帧，像立柱。
  - 宋（尚意）：速度不均，有意的轻重对比（如《寒食帖》字的大小起伏），停顿长于书写。
  - 元明（尚态）：干笔慢拖，侧锋，飞白多，停顿随意而长。
- **笔顺必须对**：凡是"写出来"的字，按真实笔顺和原迹的行笔方向渲染，最好从原迹上逐笔描出路径。

**呼吸：一段一口气**
- 每段按 exhibit-kit 的五拍：静 → 铺垫 → 那一刻 → 沉淀 → 交接（STANDARDS §1）。
- **那一刻之前**要有 0.6–1.2 s 的完全静止（画面不动，声音也收），这就是王国维说的"由动之静"[S7]。
- **那一刻之后**的沉淀，时长不少于那一刻本身的 1.5 倍〔设计值〕，让观众来得及想"原来它们是连着的"。
- 墨的扩散、颜料的沉降、印泥的吃纸，一律按真实的时间尺度或其等比放慢，不要加速到"弹出"。墨在湿纸上洇开，是先快后慢的扩散，边缘随纤维呈不规则的毛边（参 THEMES：离线模拟，纸纹用真实宣纸扫描）。

**不做的运动**：弹跳（bounce）、回弹过冲超过 3%、抖动（shake）、闪白、快速变焦（whip）、旋转飞入、粒子爆散。这些是另一种文化的节奏。

### 2.3 色彩

**原则**：颜色取自**所挂原作的高清图实测**，不从"中国色"色卡或网络调色板里挑。下面的数值是起点：一部分是我从维基共享资源的缩略图上实测的（方法：k-means，缩略图宽 960 px，已注明），其余是〔设计值〕。

| 名 | 用途 | 数值 | 依据 |
|---|---|---|---|
| **墨五色** | 墨的层级：焦、浓、重、淡、清（常见分法[S9]；源自"运墨而五色具"[S8]） | 按 L*（CIELAB）叠在底色上：焦 8–12，浓 18–25，重 30–40，淡 55–65，清 75–85（再高就近于纸）〔设计值〕。实测《溪山行旅图》缩略图最暗 3% 像素的中位数为 **#161212**，偏暖，不是纯黑 | 墨要做成**乘在底色上的透射**（multiply／透过率），不能用灰色 alpha 叠加，否则纸纹会被盖住、墨色发灰。墨色偏暖或偏冷，看原作实测；通行说法是松烟墨偏冷、哑光，油烟墨有光泽〔待核〕 |
| **绢（古）** | 宋代绢本的底色 | 《千里江山图》（1113）局部：绢地约 **#7C6D3F – #907B47**；《溪山行旅图》：约 **#5E4B3A – #82694A**（已严重变暗） | 实测，缩略图（[S20][S21]）。这是**变旧后的颜色**，观众认得的正是它。不要"修复"成新绢的白 |
| **纸** | 宣纸、元明纸本 | 新纸 L* 92–95，a* 0–2，b* 4–8（暖白）；古纸 L* 80–88，b* 12–20〔设计值，待用真实宣纸扫描校准〕 | 纸本比绢本亮得多；元代"纸取代绢"时，画面的整体明度要上一个台阶 |
| **石青** | 青绿山水 | 《千里江山图》缩略图的蓝绿像素聚类：**#47656E**（38%），**#2E484B**（20%） | 实测。原作照片里的石青是灰蓝的，不是湖蓝 |
| **石绿** | 同上 | **#678275**（22%），**#526A4F**（20%） | 实测。石青石绿的饱和度要**低于**直觉；"颗粒一层层落在绢上"一类的转场，颗粒刚落下时可以稍鲜，落定后收到上述值〔设计值〕 |
| **朱（印泥、朱砂）** | 印章；汉漆的朱 | 印泥在旧纸上约 #A83A2C – #C4492F，L* 40–50〔设计值，待从原作印章实测〕 | 本次抓的《溪山行旅图》印章图是带标注的灰度图，无法取色。下一步从原作高清图的印章处实测。印泥是全片**唯一**允许的高彩度红，每个镜头至多一处 |
| **青铜** | 青铜段 | 取所挂器物照片实测：铜绿锈（灰绿）与铸面（暗褐）两组 | 不要金色，也不要"金属高光" |
| **装裱绫绢** | 画面外框、墙色 | 取原件装裱的绫色实测（常见米色、浅灰蓝、浅绛）〔待核〕 | 对应 exhibit-kit 的 `frame`：天头、地头、隔水 |

**色彩纪律**
- 整片画面的主要成分是墨和底色。彩色只出现在它所属的时代，并且来自原作本身（"随类赋彩"[S4]，不是随意赋彩）。
- 张彦远的警告："意在五色，则物象乖矣"[S8]。所以画面里要是同时出现三种以上高彩度颜色，就是出错了。
- 调色时不整体加暖、加暗角、加胶片颗粒。古画"旧"在它自己的颜色里，不在滤镜里。

### 2.4 字

- **竖排，从右往左**：`writing-mode: vertical-rl`。数字用汉字（"一一一三年"或"宋 · 政和三年"）。标点用竖排字形，避头尾（STANDARDS §3）。
- **字体**：正文用思源宋体（OFL）；需要手写气的，用霞鹜文楷（OFL）；都要自托管并子集化（THEMES）。**不用**"毛笔字体"或"书法字体"做字幕。
- **题签、片名**：用**集字**，从公有领域的原迹中逐字取出（集字是正统做法，唐代怀仁集王羲之字刻成《集王圣教序》〔待核年代〕）。集字的每个字都要记下来源帖名和位置。
- **题款位置随时代变**（李泽厚[9.4]）：
  - 宋以前的段落：字幕要"藏"，放在画外（绫边、画框外），或者小而淡，放在画中不重要的角落。
  - 宋：一行细字，贴边，不侵占画面。
  - 元以后：字可以进入构图，成为画面的一部分，但位置要按题跋的逻辑放在空白处，不压画。
- **印章的规矩**（据书画钤印的通行规则[S17]）：
  - 引首章在起首（竖排的右上）；名章在署款之下，若款下没有空白，"宜左不宜右"；压角章在左下，与引首章成对角之势。
  - 三方章不排在一条直线上；印与印之间留间隔，"既忌拥挤，亦防松散"。
  - 朱文印分量轻，白文印分量重。淡墨的画面用朱文印，浓墨的画面用白文印。
  - 片尾若要盖一方印，要按上面的规矩放，而且只盖一次。不许把印章当成每个镜头角落里的装饰。
  - 印文内容要真实：用原作上的真实印章（注明是谁的印），或者本项目自刻的印；不要拼凑假的古印。

### 2.5 声音

- **古琴为主**，一件乐器。依据：老子"大音希声"[S22]；明代徐上瀛《溪山琴况》以"和、静、清、远、淡、恬"等二十四况论琴〔二十四况的具体名目待核〕[S23]。
- **希声**：音少，每个音的余韵（泛音、走手音）都要放完，不能被下一个音切断。按音、散音、泛音的交替可以对应画面的实与虚〔设计值〕：墨落下时用按音或散音，空白时用泛音或静默。
- **留白的静**：
  - 全片至少有 2 处完全的静默（≥ 1.5 s），放在最重要的两个"那一刻"之前。
  - 静默不等于音轨为零：底下留很轻的"物"的声音，比如纸的摩擦、笔落纸、卷轴展开、印泥按下。这些都录真实的声音，不用素材库里夸张的拟音。
- **禁止**：合成的古筝刮奏（五声音阶的上行滑音），电子鼓点，史诗式的弦乐铺底，"中国风"流行编曲，以及用锣、钹制造冲击。琴曲录音的许可要逐个核实；找不到合适授权的录音，宁可只用环境声（THEMES）。
- **声画关系**：音乐也要按"一笔"的节奏：起音前有一口气（静默 0.3–0.5 s），乐句的结尾要与画面的收笔对齐，不要让音乐的高潮抢在画面的"那一刻"之前。

### 2.6 剪辑节奏

- **不剪**：每个时代段是一个连续的镜头，一口气完成。段与段之间的交接只用一种物质逻辑：墨洇、展卷、落印、颜料沉降、窑火、铸造、干湿、时间剥落。不用叠化、硬切、闪白。
- **时长**〔设计值〕：总长 90 s 左右，大约 8–10 段，每段 7–11 s。北宋全景和南宋一角这两段可以最长（让留白有时间"成立"），盛唐狂草这段最短。
- **快慢对比**只有一次高峰：盛唐狂草（最快）。高峰之后紧接着的一段要最慢、最空（中唐到宋的"淡"，或南宋"一角"），这就是王国维说的"由动之静"，也是全片的转折。
- **开头与结尾**：开头从一张空的纸（绢）开始，静默 1.5–2 s，然后是第一笔；结尾回到空白，最后一方印落下，余音放完再黑。首尾是同一个"空"，但结尾的"空"已经被整部历史填满过一次。
- **不剧透**：下一件作品只能在那一刻出现（STANDARDS §1）。

## 3. 反面清单：什么会显得廉价的"中国风"

| 做法 | 为什么廉价 | 用什么代替 |
|---|---|---|
| **红金配色**、满屏大红、金色描边 | 这是节庆和商业包装的色彩，不是书画的。文人书画以墨为主，"意在五色，则物象乖矣"[S8]；李泽厚说明清工艺的趣味"与……进步思潮，则是恰好相反的"[10.4] | 墨 + 纸/绢底色；朱只在印章上 |
| **满屏祥云、回纹、如意纹填空** | 用装饰把空白填满，违背"有画处多属赘疣""无画处皆成妙境"[S6] | 空白就留着，让空白成为雾、水、天 |
| **笔刷滤镜**、"水墨风"风格化滤镜、AI 水墨化 | 没有起笔、行笔、收笔，没有"骨法用笔"[S4]；纹理重复，每一笔都一样，没有气韵 | 按笔顺逐笔渲染，由速度、墨量、纸纹决定线宽和飞白 |
| **剪纸、皮影贴图**，平面素材拼贴 | 民间媒介脱离语境来当"中国元素"用；拼贴违反"一套连续的物理逻辑"（STANDARDS §1） | 只用所挂原作自己的材料 |
| **合成古筝**、五声音阶刮奏、"中国风"流行编曲 | 声音上的红金配色；与"大音希声"[S22]相反，用音符填满空白 | 真实录音的古琴，稀疏；静默 |
| **中国结、灯笼、熊猫、卡通龙、太极八卦、书法"福"字** | 旅游纪念品的符号，与"艺术的演变"无关 | 不用 |
| **水墨转场模板**（墨滴落水扩散、墨团溶解、墨迹擦除） | 就是 STANDARDS 禁止的"斑块溶解"；墨团的形状和两件作品都没有关系 | 让上一件作品里**真实存在**的那块墨，沿纸纤维洇开，而且洇开的形状是下一件作品的形（THEMES 转场点子 1） |
| **3D 摄影机飞进山水**、景深虚化、广角推进 | 单点透视加西方摄影的逻辑，与"以大观小""散点透视"相反[S12][9.2] | 平面平移与正面缩放；层与层之间只有很小的平移 |
| **体积光、丁达尔光束、镜头光晕、金色粒子** | 西方的光影戏剧；北宋山水"不重视诸如光线明暗、阴影色彩的复杂多变"[9.2] | 用墨的浓淡和留白表现远近与气氛 |
| **仿古做旧**：泛黄滤镜、暗角、划痕、胶片颗粒 | 旧是假的，而原作的旧是真实的 | 用原作的实测底色（见 2.3） |
| **过饱和的石青石绿**（霓虹湖蓝、翠绿） | 原作照片里的石青石绿是灰蓝、灰绿（实测，见 2.3），过饱和一眼就是"电脑色" | 实测值 |
| **书法字体做字幕**、假飞白、笔顺错误的"写字"动画 | 懂书法的人一眼就能看出笔顺错误；字体不是书法 | 宋体、楷体做字幕；标题用集字；书写动画按原迹笔顺 |
| **印章当装饰**：每个画面角落一方印、假古印 | 印章代表所有权和经手的历史，有位置规矩[S17] | 只盖有意义的印，按规矩的位置盖 |
| **竖排字但标点、数字横躺**；中英混排的竖排 | 排版不专业 | `vertical-rl`，竖排标点，数字用汉字 |
| **满屏的大场面**：万里江山航拍式俯冲、群山从地里升起 | 用户已明确：惊艳来自巧思，不来自规模（LESSONS §1） | 一个发现，一句话说清 |
| **史诗旁白**、"五千年""泱泱华夏"一类的宏大叙事字幕 | 口号不是美学；与"韵外之致"那种"近而不浮，远而不尽"[S15]相反 | 字幕只写作品名、年代和一句发现；可以不写 |
