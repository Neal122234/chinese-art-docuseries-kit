# 质量标准与审美（用户定的）

每条后面的〔来源〕写的是哪次反馈定下的，方便判断前提还成不成立。日期是 2026 年。

## 0. 先读：这份标准怎么用

- **标准是对标，不是笼子。** 给创作助手的 brief 只写两样：对标样板（说清好在哪）+ 用户明确否定过的底线（§9、§10）。其余全部放开：光、立体、速度、整屏、声音带转场都可以。理论文件（`research/early/aesthetics_theory.md` 等）只作参考，不把里面的数值写成硬规则。创意阶段先发散，再挑最好的。〔09-27 先导片：我把留白比例、缓动参数、"不许有光"写成硬规则，出来的方案平庸。用户："我本意是想让你达到那个质量标准，不是限制你的发挥和创造"；"越能让我惊艳越好"〕
- **反馈只作用于那一件。** 用户针对某集某件作品的意见，只改那一件；觉得能推广到别处，标成"建议"问一句，不直接下发成所有在做的活的硬规则。用户说"以后都…"才推广。本文件里标了"系列原则"的，是用户明确说过要全系列照做的。〔09-30 edit-lab：把一件作品的结尾意见推广给 5 个在做的助手，用户纠正"不要直接限死，这样重修多浪费成本"〕
- **客观的自己查，主观的交用户。** 自动评审只查可验证的：规则推演、标准合规、已否内容是否混入、数字是否自洽。好不好看、选哪个方向，列对照表交用户拍板，可附推荐。用户明确授权（"让评审调完我再来审核"）时，评审可以先挑，但要写理由和第二名。〔09-27 用户："review 是客观因素还是主观的，主观的就交给我"〕

## 1. 内容：这一集讲什么

| 标准 | 来源 |
|---|---|
| **一集一个论点，一句话说得清**，每件作品挂在论点上。北宋"看得真"，南宋"只留最要紧的一笔"。下一集的论点要和上一集形成对照（南宋开头就是"北宋人要看得真"）。 | 09-28 先导片被整体否定："没有抓住重点，不知所谓"。复盘：125 秒塞 16 件、零旁白 |
| **每朝选成就最高的门类**（青铜、雕塑、书法、壁画、宋画宋瓷……不只限绘画），以学界共识为准。 | 09-28 用户定 |
| **要有介绍**：中文旁白 + 同步字幕；讲出朝代特点，**讲到哪里画面就停在哪里**（说雨点皴，画面上雨点皴一层层积出来）。 | 09-28 否定原话："画都没有展示全貌，也没有介绍""每个朝代的艺术特点没有表现和介绍" |
| 每集约 5 分钟、4–6 件作品；每件讲 40–80 秒。一集收尾用几个竖排小字总结各件（"真山 人间 青绿 天青"），再出"下一章　某朝"。 | 两集的实际做法（参考值，不是用户硬规定） |
| 旁白约 180–200 字/分钟，全集留 20–30% 无旁白的"呼吸段"；每个"发现"前停 1–1.5 秒。 | `research/series/visual_refs.md` §0（研究建议，两集照此执行） |

## 2. 作品为主、特效为辅（系列原则）

> 用户原话："重点是给观众展示各朝代的艺术作品和艺术特点，所以艺术作品是关键，转场和动效只是让视频更加吸引观众的手段。"〔09-29 看完南宋第一版〕

| 标准 | 来源 |
|---|---|
| **每件作品的全貌干净停 ≥6 s**：不被雾、光效、字盖住。设计分镜时**先排作品展示时间**，再往里加转场和高光。 | 09-29 南宋 v1："云雾转场太多……有时候会遮住画" |
| **不做小展板**：全貌不能是空背景上缩着一幅小画。立轴挂墙、整轴含装裱按高度放入，两侧是真实绢/绫材质（从原作空白绢取样）；手卷用长案透视全貌（整卷平铺长案向远处延伸，暖光走卷，镜头俯冲入卷首）；册页、器物占画面主体，背景是柔和绢/纸色，不用黑、不漂浮。 | 先导片"画没展示全貌"；09-28 2.5D 试验帧"画缩在中间两侧模糊"被自己判为小展板；北宋 v1 反馈 3："手卷全貌是一条细线躺在大片空绢上" |
| **转场遮住作品 ≤1–2 s**；段内换景别用干净叠化（0.8–1.5 s）或直切，不用雾掠过。 | 09-29 南宋 v1 反馈 |
| **雾一集最多用一次，而且不遮主体**；能不用就不用（南宋集全片无雾）。转场优先从两件作品的本质找联系。 | 09-29 凌晨"云雾转场不要重复太多"（北宋用了两次雾）；同日南宋 v1 反馈 |
| **组画、册页、多段手卷：先逐幅/逐段完整展示（带题名），再挑一幅聚焦细看。** 逐段展示**快而看得清**：每段约 2 s（静止完整看清约 1.6 s + 0.4 s 干净叠化），展示时不推拉、不平移，整段铺满画面高度，不为此拉长全片。 | 09-29 南宋 v1："画水的那个，应该每幅给观众展示一下，然后聚焦于一幅"；补充："不用延长很多，可以快速过一下，但稍微控制一下速度，不要让观众什么都看不清" |

## 3. 动静结合，动效一眼可见（系列原则）

> 用户原话："整体比较典雅或者说淡雅，有没有办法适当增加一些视觉冲击感……这样动静结合；还有就是我看到你做了画面的动效，但是效果不明显。"〔09-28 看完北宋 v1〕看第二版预览："这个感觉对了。"——后面各集照这个力度。

| 标准 | 来源 |
|---|---|
| 安静的部分保留（全貌停留、读画、字幕节拍）；**每件作品加 1–2 个"动"的高光**，冲击来自这件作品本身的本质。 | 09-28 北宋 v1 反馈 |
| **动效要明显：手机上 1 秒之内能看出东西在动。** 量级（720p）：水流、瀑布纹理平流 15–40 px/s；雾/云层相对速度 10–25 px/s；船、驮队一个镜头走 1–3 个身长（刚体位移 + 轻微起伏）；视差最大画宽 5%。 | 同上（UPGRADE_v2 定的量级） |
| 冲击来自画里的变化、光、层次和揭示，**不靠快甩镜头**（镜头限速不变）。允许：光（柔光、一束光落到发现处）、景深与焦点转移、更强的分层视差、镜头穿过前景层、按原作像素"揭示"（墨一层层积出来、颜色一层层罩染出来）、尺度反差。 | 同上 |
| **对标样板**：北宋片头「北宋」按笔顺落墨、雾多层翻卷、溪山穿雾峰顶先露、雨点皴分三批积墨、名款一束柔光、千里罩染重画并推到满屏石青、汝窑柔光扫釉；南宋李唐斧劈一斧一斧显出、宁宗题诗逐笔写出、"留白"墨退回绢里只剩一只船、泼墨从落墨中心洇开、官窑开片随光亮起。西方厅：卡拉瓦乔"一道光选中马太"、弗里德里希"雾吞掉网格"——惊艳，而且就是这幅画最本质的东西。 | 09-28 "这个感觉对了"；西方厅 09-25 验收偏好 |

## 4. 镜头速度（防晃眼）

〔先导片被否原话："移动的非常快，甚至有点晃眼睛"。复盘实测：32% 的时长超过 1/7 画宽/秒，峰值是上限的 29 倍〕

| 参数 | 720p（草稿与现行成片） | 1080p |
|---|---|---|
| 平移（屏幕中心画面点位移） | 推荐 2–3.3 px/帧，**硬上限 6 px/帧** | 推荐 3–5，硬上限 9 |
| 推拉 | ≤6%/秒，按对数匀速；推荐 3–6%/秒 | 同左 |
| 缓入缓出 | 每端 ≥1 s | 同左 |
| 旋转 | 0° | 0° |
| 视差（最近层相对最远层） | 推荐画宽 2–3%，最大 5% | 同左 |
| 运动模糊 | 禁止整屏拖影 | 同左 |
| 细节停留 | 4–8 s，与旁白一句对齐 | 同左 |

- 依据：摄影防抖动的"7 秒规则"（每秒平移 ≤1/7 画宽），宋画是高对比细线又没有真快门模糊，推荐值取上限的 1/3–1/2。详见 `research/series/visual_refs.md` §3。
- 交付前必跑 `engine/tools/pan_speed_check.py`：超过 1/7 画宽/秒且连续 >0.2 s 的段落要为零（无纹理渐变处的孤立单帧误报人眼复核即可）。引擎渲染前也会自动查，超速直接报错退出。
- 走法跟着画的形制：手卷从右往左展，立轴自下而上（高远），平远横移，深远穿过云烟层。

## 5. 转场

| 标准 | 来源 |
|---|---|
| **一个转场只做一个发现**，≤15 s，能用一句话说清；方案里只留一个核心，不拼盘。 | 西方厅 09-25 第三批反馈："视觉冲击很强……但巧思不够，少了惊艳" |
| 衔接满足**一点或几点**即可：惊艳、巧思、结合时代特点、视觉效果、结合画作特点。理想是又有联系又惊艳；次一等是视觉极强但联系少，也可以。 | 09-27 先导片用户定的转场标准 |
| 优先从**两件作品的本质**找联系（踏歌的墨退回绢里→只剩寒江一只船；寒江的涟漪→水图的水纹；浪涌→泼墨；泼墨干裂→官窑开片）。整屏的氛围或材料现象也可以（烟霭、泥金、雪、水、墨晕、月色），只要是新作品的本质。 | 09-27 用户补充转场；09-29 "转场优先从两件作品的本质找联系" |
| **设计转场先算限速下镜头能否到位**：从全景到特写要走多少倍、多少秒，按 ≤6%/s 推拉算得出来再定。**全景尺度的切分必然是拼贴**。 | 09-29 "斧劈接斧劈"失败：全景斜切成条 = 拼贴，限速下 9 s 推不到特写（见 `LESSONS.md`） |
| 跨载体（画 ↔ 器）要自然：交接那一刻两种载体不同屏，用有理由的遮挡（暗、整屏云、光圈）隔开 ≤2 s；或让变化落在共有的物理量上并连续（同一色系、同一道光）；只用真照片里本来就有的东西，合成物理过程必露馅。北宋"石青→天青"就是同色系。 | 09-30 网站阶段自然性实测（`research/hall_v3/transition_vocab.md` 同期），对纪录片是**建议** |
| 中国材料的转场语法（墨、绢、卷、印、釉、水、云气），不借西方油画"色彩/光直接变过去"那种转法。语法库在 `research/hall_v3/transition_vocab.md`（18 种），每处单独围绕两件作品设计，类型只是语法不是模板。 | 09-30 网站阶段用户要求，对纪录片是**建议** |

## 6. 只动原作像素，不重画

〔09-27 先导片技术定调：合成洇墨两轮仍像墨珠/水渍，用户否；改"揭原作之墨"后一直沿用。UPGRADE_v2 重申"用原作像素分解，不重画"〕

- **揭原作之墨**：墨、颜色、字的"出现"都是把原作真实的像素按浓淡/颜色/笔顺分批显出来，末帧 = 原作。书法按原迹笔顺逐笔揭；泼墨用湿前沿从落墨中心洇开（不编造笔顺）；开片只沿照片里真实存在的裂纹亮起（不生成裂纹）。
- **只动画里本来有的东西**：烟云、水、瀑布做流动/漂移（沿真实纹理方向）；人、驴、船只做刚体小位移（≤3 个身长）加 ≤1° 起伏；**不做肢体变形、不做网格扭曲**。
- 分层接缝藏在云烟、水面、留白里；补洞只能用绢/纸底色纹理。
- 调色只做全局校正对到馆方参照图（清明对故宫官网虹桥段），不做风格化，不做仿古滤镜。

## 7. 画面上的字要严谨，看不见的地方配合得上就行

〔09-27 用户："有些不直接展示或者说明的内容不需要那么严谨"；09-28（另一项目）："有一些艺术加工是可以的"〕

- **观众看得到、读得到的逐条核**：作品名、作者（"传"要写）、年代、材质、尺寸、藏地、旁白里的史实。以馆方页面为准（台北故宫典藏资料、故宫博物院藏品页、东博 ColBase、大都会 API），在素材 INDEX 里写出处。拿不准就换稳妥说法或不写（寒江独钓尺寸核到 ColBase 才写上；"走得更远"这类措辞，原作可能被裁切过，就别暗示空白全是画家本意）。
- 展签原文照馆方：寒江独钓写东博原文「絹本墨畫淡彩」；泼墨仙人馆方题名无"图"字就写「潑墨仙人」。
- 不展示、不说明的细节（配乐乐器年代、音效来源、没写进文字的工艺细节）贴切就用，不为此卡进度、不向用户请示。叙事上的时间压缩、戏剧化可以，只修画面上会直接露馅的错误。
- **展签**：竖排，思源宋体，全貌时出、读画前收，720p 约 24–26 px，暖白或墨色，放在画侧空白处；数字用汉字；格式「作品名／朝代　作者／材质／尺寸／藏地」。
- **字幕**：横排底部居中，一行 ≤16 字（超长在空格处拆条），思源宋体 Regular 32 px（720p），#EDE6D8 + 1 px 柔阴影 + 淡柔光晕，无底框，淡入淡出 0.3 s，按语音对时。
- **朱红只给原作真印**；不把印章当装饰。

## 8. 声音

| 标准 | 来源 |
|---|---|
| **一集一首完整录音连贯铺底**，从头淡入 2 s，在乐句尾淡出；**中间不剪、不拼、不循环、不插其他乐器**。 | 先导片否定原话："背景音乐短短续续，并不连贯，乐器的接入非常突兀"；更早的单音采样接力小样古琴、琵琶发假 |
| 选曲第一看**杂音少**（底噪、嘶声、爆音都测），再看气质和时长是否正好落在片长里。现役：Rafael Caro《梅花三弄》（CC BY 4.0）。 | 09-27 用户选 Caro 的理由："杂音最少" |
| 版权可以适当放宽（非商用艺术展示，署名写清演奏者、出处、版权方，真实版权状态照实记录、不编造）；**但要公开发布的，选曲时就要许可干净**。 | 09-27 "版权问题可以适当放宽一些标准"；09-29 南宋发布前把未授权的吴兆基录音换成 Caro |
| **旁白只要男声，音色定为云健**：edge-tts `zh-CN-YunjianNeural`，pitch −4Hz，rate −12%（个别句按对时需要提速，最快 +0%）。换声只需重合成 + 重混音。 | 09-28 用户在所有候选（edge-tts 五种、本地开源克隆、网上男声参考音）里只认云健；付费 MiniMax 没同意用 |
| 电平：人声 −16 LUFS；配乐字幕区约 −26 LUFS、呼吸段约 −20 LUFS，≥1.5 s 缓变；人声下配乐再让 4 dB；真峰值 ≤ −1 dBTP；成片整体约 −17～−19 LUFS。 | 两集实测做法 |
| **读音要对**：合成后用 whisper 听写回来逐字比拼音，读错的只在送去合成的文本里换同音字，字幕原文不动。 | 两集共 8 处读音修正（见 `LESSONS.md`） |

## 9. 中式美学

〔09-27 用户："中国厅/先导片必须体现中式美学"；09-29 网站阶段再强调"中国的一定要体现中式艺术和中国美学的特点"〕

- 顺着中国艺术本来的观看方式走镜头：手卷卧游（从右往左展）、立轴仰观（自下而上）、册页逐开、器物把玩（光扫过器身）。三远就是运镜，手卷就是时间，烟云就是转场，釉光就是宋瓷。
- 材料与声音用中国的：绢、纸、墨、矿物色、釉、印、古琴。空白就留着，让空白成为雾、水、天。
- 各朝的审美气质要拉开（北宋"看得真"、南宋"一角留白"、元人逸气……），不是全系列一个淡雅模板。〔09-29 网站阶段提出，对纪录片是建议〕
- **底线（用户否定过的"廉价中国风"与画面做法）**：拼贴感、橡皮式变形、斑块/矩形溶解、漂浮剪影、糊图、整屏拖影、快速横移、纯黑屏、画缩成空背景上的小展板、祥云壁纸、红灯笼、金色粒子、光斑、3D 翻页、滥用书法字体、采样拼接的音乐。〔先导片被否 + 北宋 UPGRADE_v2 底线〕
- 参考（不是硬规则）：`research/early/aesthetics_theory.md` §3 反面清单（红金配色、水墨转场模板、仿古滤镜、过饱和石青、史诗旁白等）。其中"体积光"一条已被用户放开：柔光、一束光落到发现处是允许的。

## 10. 用户否定过的做法（不要再做）

## 11. 工作方式（用户的偏好）

- **要速度**：开工先报预计耗时；不做内部评审，做完直接交；用户自己验收。〔09-28 "不用核查直接开渲"；早先多个项目"检查工作我来就好了"〕
