## 转场实现（`assemble/assemble.py` 的 `TRANS`，实现在 `assemble/transfx.py`；全片没有雾）
1. s0→s1（7–9）：叠化，绢底叠入万壑松风全貌。
2. s1→s2（52.0–53.5）：两幅挂墙全貌之间干净叠化。
3. s2→s3（108–117）：**留白**（`transfx.Liubai`）。墨模型：画面 = 绢底 × (1−墨)；每个像素的"退墨时刻" = 浓淡分位（权重 0.8）+ 竖直位置（0.2，上方先退），退的途中墨略晕开；左下巨石一角另排到 112.7–113.9 才退；112.9–113.9 空立轴连同投影隐入墙；113.4–114.9 墙面光色转到寒江那面墙、寒江空绢显出；船、渔翁、竿、钓丝 113.9–115.8 由浓到淡显出。首尾帧与 s2/s3 逐像素一致。两张底图：寒江全貌去船（`work/render_hj_blank.py`）、踏歌全貌只剩墙（`work/render_tage_wall.py`）。
4. s3→s4（166–172.7）：**涟漪变水图**（`transfx.Ripple`）。波前与涟漪同心（入水点 666,304）、同纵横比 0.40，166.3–172.6 自内向外推；前沿外的涟漪线先加深，经过处寒江细节退、洞庭风细的水纹线进；金黄绢渐转灰绢。
5. s4→s5（216.1–220.0）：**浪涌成泼墨**（`transfx.Surge`）。216.2–217.6 浪线的墨叠 1→1.85 遍并沿线洇开（wash 最多 18%）；217.3–219.0 逐像素由积浓的浪墨过渡到泼墨（纸处先清、越近衣袍墨芯越晚定，过渡半宽 0.45 s），底色绢灰→纸黄（217.2–218.9）。
6. s5→s6（246–252.3）：**墨干成开片**（`transfx.Crack`）。246.4–248.0 墨面干；247.0–249.8 裂纹从 (700,300) 附近沿开片线以 1100 px/s 跑开；249.4–252.2 化为釉面，裂纹网与 s6 开片逐像素重合。
7. s6→s7（281.0–283.2）：叠化，全器淡为绢底（s6 背景本就是 s7 那块绢）。

## 字幕与声音
- 字幕：`out/subs.srt`（配音流水线按语音对时写出，44 句 → 48 条，超 16 字在空格处拆条），思源宋体 Regular 32 px，#EDE6D8 + 1 px 柔阴影 + 淡柔光晕，无底框，淡入淡出 0.3 s（同北宋集）。
- 配音：云健（`zh-CN-YunjianNeural`，pitch −4Hz，rate −12%）。读音替换：「一一二四年」→「壹壹贰肆年」（两个"一"连读粘成一个）；「朝阳」的朝 →「招」（被读成 cháo）；「一整卷」的卷 →「绢」（被读成 juǎn）；句首「笔越少」的笔 →「比」（被听成"别"）。
- 配乐电平：`assemble.py audio` 按字幕区压到约 −26 LUFS、呼吸段约 −20 LUFS → `assemble/work/music_mix.wav`；再由 `voice/build_voice.py mix` 在人声下再让 4 dB、人声归一 −16 LUFS、4× 过采样限幅 −1.5 dBFS → `out/audio/mix.wav`。配乐来源见 `music_DECISION.md`。

## 自检结果（第二版画面；发布版只换了音轨）
- 音画同长：视频 8880 帧 296.000 s，音频 296.000 s；faststart 是。
- pan_speed_check：全片超限 0.0 s，峰值 0.10 画宽/秒（限 0.143）。黑帧 0；帧间跳变 0（最大帧差 7.9，174.4 s 水图拉出）。全片最低平均亮度 15%（295.9 s，片尾压暗，设计如此）。
- 全片无雾：`TRANS` 里没有 fog；s1、s2 段内雾/云带代码已关，重渲帧抽看无雾。
- 浪涌：平均亮度低于两端 80% 的时长 1.07 s（217.00–218.07），最暗帧平均亮度 27%。
- 字幕对语音：首条字幕起点与人声起音相差中位 −10 ms、最大 40 ms；末条字幕止于 289.73 s。
- 作品全貌干净停住：万壑松风 8.7–17.6（8.9 s）+ 48.6–52.2；踏歌 53.3–61.5（8.2 s）+ 103.4–110.0（6.6 s）；寒江独钓 114.5–128.9（14.4 s）；泼墨仙人 228.0–232.9（**4.9 s，不足 6 s**）；官窑 275.2–281.5（6.3 s）+ 262.2–263.6。
- 水图十二段：每段整段静止 1.60–1.67 s，段间 0.4 s 叠化；长案全卷静止 178.8–179.4。
- 转场遮挡（混合 / 看不清）：叠化 s0→s1 1.37 / 0 s，s1→s2 1.07 / 0 s，留白 1.13 / 0.03 s，涟漪 1.37 / 0.20 s，浪涌 2.13 / 0.10 s，开裂 1.20 / 0 s，s6→s7 0 / 0 s。
- 16 帧联系表看过：无雾、无错位、无方块字、无硬边。

## 已知不足
- 泼墨仙人全貌干净停住只有约 4.9 s（要补得重渲 s5 把全貌停长约 1.5 s）；水图长案全卷真正静止只有 0.6 s，靠十二段逐段展示补足。
- 浪涌：墨"收拢"途中（约 218.0–218.5）衣袍边缘偏软；按"混合"口径 2.13 s，略超 2 s。
- 留白：换底（立轴→横幅、暗墙→亮墙）是两步叠化，不是墨驱动的；踏歌空绢是拟合绢色加绢丝纹理；"一角"用椭圆区域圈定，右缘有一段偏直。
- 涟漪变水图：是前沿带里线对线的替换，不是把圆环几何地扭成水纹。
- 墨干成开片：部分开片线是从微距照片细线滤波找出的，裂开时有些线是虚线状。
- s2 宫阙中景（77–83）去雾后只剩缓移镜头。
- 字幕压在立轴下沿（万壑、踏歌全貌时字幕在画心下端约 70 px 内）。
- 换配乐后，踏歌顿足没有对新曲重新对拍。
