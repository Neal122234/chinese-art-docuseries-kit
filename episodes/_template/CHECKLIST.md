# 检查清单（每集复制一份勾）

标准出处见 `docs/STANDARDS.md`，做法见 `docs/PLAYBOOK.md`。只列客观能查的项；好不好看交给用户。

## 开工前
- [ ] 读过 `docs/STANDARDS.md`、`docs/LESSONS.md`、上一集 `plan/FINAL.md`（知道用户认可的力度和上一集的已知不足）。
- [ ] `scripts/bootstrap.sh --check` 通过（python ≥3.10、ffmpeg、思源宋体；读音核对要 whisper 环境）。
- [ ] `CHINA_ART_ROOT`、`EP_DIR`、`LOCK` 已定；`EP_DIR` 子目录已建；`EP_DIR/plan` 软链接到 `KIT/episodes/epNN_<拼音>/plan`。
- [ ] 用户已拍板：朝代与论点、作品清单、片长、是否 1080、配乐（沿用 Caro 或换曲）。
- [ ] 上一集的文件只读；公共代码（`engine/`、`pipeline/`）只新增、不改已有行为。
- [ ] 长流程已开 keep-awake；看过内存（`vm_stat`），别的会话在跑重活时减并发。

## 分镜
- [ ] 论点一句话，能在画面上被证明，和上一集对照。
- [ ] 每件作品：全貌干净停 ≥6 s（不被雾、光效、字盖住），不做小展板（立轴挂墙 / 手卷长案 / 器物占主体）。
- [ ] 组画、多段手卷逐段展示（每段约 2 s，带段名），再聚焦一段。
- [ ] 每件 1–2 个高光，写清用原作的什么像素、怎么动。
- [ ] 每个转场：一句话说清的发现；可达性算过（景别倍数 ÷ 推拉 ≤6%/s ≤ 窗口）；遮挡 ≤2 s；雾全集 ≤1 次。
- [ ] 段窗口表首尾相接、重叠留够转场；需要的遮罩写明由哪段导出。
- [ ] 旁白约 180–200 字/分，呼吸段占 20–30%；每条字幕 ≤16 字；`anchors.json` 与分镜一致。
- [ ] 展签文字对馆方原文（名称、作者含"传"、材质、尺寸、藏地），数字用汉字；拿不准的不写。

## 素材 / 配乐 / 旁白
- [ ] 每件作品：原图原样保留一份；来源 URL、许可、署名写法、像素写进 `assets_INDEX.md`。
- [ ] 参照图（校色、对照）核过是哪一本（摹本、仿本、传本）。
- [ ] 坐标在网格核对图上看过。
- [ ] 配乐：时长 = DUR；中间无剪接；淡出在乐句尾；**要公开发布的许可干净**；`music_DECISION.md` 写了许可与署名。
- [ ] 旁白：每句放得下、不重叠；asr/variants 读音报告已处理（多音字、年份、专名）；`PRON` 只改合成文本，字幕原文没动。

## 分段
- [ ] 每段先出 ≤10 s 高光预览并看过关键帧（需要时发给用户）。
- [ ] 起止状态符合段窗口表；帧 0 = 窗口起点；1280×720 30 fps。
- [ ] `pan_speed_check` 无超限段（孤立误报人眼复核过）。
- [ ] 动效手机尺寸 1 秒内看得出；只动原作像素，没有橡皮变形、没有生成原作里没有的东西。
- [ ] `beats.json` 已写。
- [ ] 重活都在锁内；长命令后台 + 短轮询；覆盖前 cp 备份（不用硬链接）。

## 交付前（客观自检）
- [ ] 音画同长 = DUR（到毫秒）；faststart。
- [ ] 响度：人声 −16 LUFS，全片约 −17～−19 LUFS，真峰值 ≤ −1 dBTP。
- [ ] 黑帧 0（设计的压暗除外）；帧间无意外跳变。
- [ ] 每件作品全貌干净停住 ≥6 s（列出实测时段）；每个转场遮挡 ≤2 s（列出实测）。
- [ ] 组画每段静止 ≥1.5 s。
- [ ] 用了雾的话，雾不平涂检查通过。
- [ ] 字幕对语音（起点差最大 ≤50 ms）；字形无方块字。
- [ ] 16 帧联系表用 Read 看过：无错位、无硬边、无雾遮画。
- [ ] `HANDOFF.md` / `FINAL.md` 写好：文件、高光时间码、转场实现、重跑命令、自检数字、已知不足——只留最终版本。
- [ ] 发给用户：成片（手机需要时 <30 MB 版）+ 简短说明 + 要他决定的事。

## 发布前
- [ ] 标题、分区、封面（写字）用户已定。
- [ ] 简介：论点、作品、章节时间、图像与配乐署名、AI 生成声明。
- [ ] 本集代码与文档已复制进 `KIT/episodes/epNN_<拼音>/`；`docs/EPISODES.md` 已更新；`scripts/check_secrets.sh` 通过。
